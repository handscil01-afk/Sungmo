# 중계 음성 목록 (손잡다 야구)

녹음(Gemini, 2026-11-02, 8묶음 → 14파일)을 무음으로 나누고, 묶음 대본 순서·조각 길이·소리 비교(MFCC)로 문장마다 맞춰 잘랐습니다(187조각, 한 줄에 하나).
소리 내어 읽어 버린 감정 표시(또렷하게, 보통, 긴장 최고조, 차분하다가 긴장, 폭발 소리 지르듯 등)는 뺐습니다. `j_vs`("대")는 "의 공격입니다" 앞에 붙어 녹음되어 있어 나눠서 씁니다. 조각마다 맞는지는 `check.html`에서 듣고 확인합니다.
자르는 스크립트와 대응표: 이 저장소 밖(작업 기록)에 있음. 조각 끝은 다음 말 직전까지(최대 0.3초) 남겼습니다.
`index.json`의 variants가 줄마다 녹음 개수입니다. 쓰는 곳: `js/caster.js` (설정 → 읽어 주기 → 중계 음성).

게임이 상황에 맞는 조각을 골라 이어 붙여 중계합니다(내비게이션 음성처럼). 선수 이름은 부르지 않고 "타자", "투수", "3번 타자"처럼 부릅니다.
파일은 `baseball/voice/` 에 `아이디.mp3` 로 넣습니다. 한 파일에 한 줄, 앞뒤 무음은 0.1초 이하.

감정 표시: [차분] [보통] [기대] [긴장] [흥분] [폭발] [탄식] [아쉬움] [안도]

## 2차 녹음: 해설 추가, 캐스터 말 늘리기 (2026-11-04 녹음, AI Studio Gemini TTS)
- 캐스터 **이하늘**, 해설위원 **강태산** (가상의 이름). 경기 시작에 서로 소개하고, 캐스터가 득점권을 짚으면 해설이 받음.
- 대본: `script2.txt` (번호 · 묶음 · 아이디 · 문장). 녹음 안내: `prompts2/C1.txt` ~ `C5.txt`(캐스터), `A1.txt` ~ `A6.txt`(해설).
  묶음마다 말투를 하나로 정해 줄마다 감정 표시를 붙이지 않았고, 묶음 하나는 10~12문장, 문장 사이 무음 2초.
- 자르기: `python3 tools/voice2_cut.py C1=파일.wav A1=파일.wav …` → 조각 수가 문장 수와 맞는 묶음만 자르고, 소리 크기를 검사하고, `index.json`에 더함.
- 게임은 녹음이 있는 조각만 고름. 녹음 전에는 지금처럼 1차 녹음으로만 중계함.
- 설정 → 중계 음성: 끔 → 캐스터만 → 캐스터 + 해설 가끔(기본) → 캐스터 + 해설 자주.
- 결과: 11묶음 125조각. C1·C2·A4·A5는 2초 무음으로 바로 나뉨, 나머지 7묶음은 문장 사이를 덜 쉬어
  `tools/voice2_split.py`(작은 무음 조각을 문장 길이에 맞춰 묶음)로 경계를 정해 자름. 모든 조각의 소리 크기·경계 검사 통과.
