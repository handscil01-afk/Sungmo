# 선수 육성 화면 개편 계획 (화면 보며 하기)

작성: 2026-11-20. 참고: 게임빌 프로야구 "나만의 선수"(마을 지도, 라커룸 메인, 선수 카드, 훈련 타일, 대화 창).

## 원칙

- **연결은 그대로**: 육성 계산(career.js·career-life.js·career-grow.js)과 화면 정의(질문 + 번호 선택지)는 바꾸지 않는다. 화면 정의에 `kind`(어떤 화면인지)와 선택지 `key`(무엇을 하는 선택지인지)만 붙이고, 화면 보며 하기(skin.js)가 그것을 보고 그림 화면으로 그린다. 누르면 늘 같은 `choose(번호)`로 진행하므로 소리와 글로 하기와 결과가 같다.
- **소리와 글로 하기는 그대로**: 같은 선택지, 같은 번호, 같은 글. 다만 "내 가방"을 첫 화면 선택지에 올리는 것처럼 두 모드 모두 편해지는 변경은 함께 한다.
- **스크롤 없이 한 화면** 규칙을 지킨다(skFit). 휴대폰 세로가 기준, 가로·태블릿도 맞춘다.
- **규칙(밸런스)은 이번 단계에서 바꾸지 않는다**: 하루 훈련 1번, 하루 방문 1번, 가격, 성장 공식은 그대로. 새 콘텐츠(라이벌, 주전 경쟁, 스프링캠프 등)는 9-3단계에서 이 화면 위에 더한다.

## 화면 구성

### 1. 육성 첫 화면 = "라커룸" (kind: cr-home)

```
┌───────────────────────────────┐
│ 💰1088만  ❤인기28  😀아주좋음  피로▮▮▯ │ ← 자원 줄 (5시즌 1일째 · 팀 7위)
├──────────────┬────────────────┤
│  [선수 얼굴]  │ 컨택 92 ████▉ A │
│  등번호 88    │ 파워 95 █████ S │ ← 능력치 막대(성장 점수 작은 막대)
│  성모 · 지명타자│ 선구 83 ████  B │
│  [팀 엠블럼]  │ 주력 62 ███   C │
│  1군 주전 5번 │ 수비 44 ██    D │
├──────────────┴────────────────┤
│ [▶ 오늘 1군 경기]  ← 가장 큰 단추     │
│ [훈련] [마을 지도] [가방] [내 기록]   │ ← 도트 아이콘 타일
│ 순위 · 기록 순위 · 업적 · 명예의 전당 · 설정 │ ← 작은 줄
└───────────────────────────────┘
```

- 배경: 라커룸 그림(새 그림), 선수 얼굴은 고른 얼굴(faces) 큰 초상 + 팀 색 유니폼 깃.
- 오늘 훈련을 했으면 훈련 타일에 "완료" 도장, 오늘 방문했으면 마을 지도에 "다녀옴".
- 계약 제안·이벤트가 있으면 첫 화면 위에 대화 창이 먼저 뜬다(지금처럼 먼저 묻는 흐름 유지).

### 2. 마을 지도 (kind: cr-visit)

- 그림 한 장(새 그림: 위에서 비스듬히 본 도트 마을)에 장소가 있고, **장소를 눌러 들어간다**. 장소 위에 HTML 이름표(게임빌처럼 남색 간판)와 짧은 설명, 가격.
- 장소(지금 있는 기능과 1:1):

| 그림 속 장소 | 들어가면 | 지금 기능 |
|---|---|---|
| 야구장 | 오늘 경기 | 첫 화면 1번 |
| 훈련장 | 훈련 고르기 | 훈련하기 |
| 스포츠 용품점 | 장비·소모품 사기 | 용품점 |
| 광장 무대 | 팬 사인회 | 팬 사인회 |
| 코치 아카데미 | 특별 코치 레슨, 개인 코치 고용 | 특별 코치·개인 코치 |
| 병원 | 마사지(다쳤으면 재활 치료) | 마사지 숍·재활 센터 |
| 내 집 | 집 구하기, 가방 | 집 구하기 |
| 공항 | 휴가 | 휴가 |
| 구단 사무실 | 계약·연봉 협상·기부 | 계약 화면·기부 |

- 오늘 이미 다녀왔으면 장소에 "오늘은 끝" 표시(누르면 안내). 다친 날은 병원에 빨간 십자 깜빡임.
- 지도 아래에는 지도와 같은 장소 목록이 작은 단추로도 있다(작은 화면·키보드용, 번호 키 그대로).

### 3. 장소 안 (kind: cr-place)

- 위: 장소 배경 그림(cr-shop, cr-fansign, cr-rehab, cr-gym, cr-room, cr-office, 새 그림 휴가지) + 그 장소 사람(cr-people·cr-people2: 가게 주인, 코치, 의사, 단장…)이 말풍선으로 한마디.
- 아래: 할 수 있는 일 카드(물건 아이콘·가격·효과). 산 물건은 "가지고 있음" 도장, 돈이 모자라면 흐리게.
- 용품점 물건 이름이 길어 줄바꿈되는 문제: 이름 · 가격 · 상태(가지고 있음)를 따로 줄로 나눠 보여 준다.

### 4. 가방 (kind: cr-bag) — 첫 화면에서 바로

- 왼쪽: 선수 실루엣에 장비 칸 5개(배트·글러브·신발·손목·액세서리). 끼운 장비 아이콘과 내구도 막대.
- 오른쪽: 가진 물건 칸(아이콘 바둑판). 누르면 아래에 설명 창: 끼우기/빼기/수리·강화/쓰기(소모품).
- 장비로 오르는 능력치 합계(최대 10)를 막대로.

### 5. 훈련 (kind: cr-train)

- 게임빌 훈련 화면처럼 능력치마다 큰 타일(새 훈련 아이콘), 타일 안에 지금 값·성장 점수 막대·한계 표시. "푹 쉬기" 타일.
- 피로가 높으면 위쪽 빨간 경고 띠. 고르면 훈련 장면(지금 있는 cr-train 움직임) → 결과 카드(오른 능력치 +1 반짝임).

### 6. 내 선수 카드 (kind: cr-info)

- 선수 카드: 얼굴·등번호·엠블럼·포지션·유형·나이, 능력치 막대와 등급, 이번 시즌 기록 표, 통산 기록 표(쪽 넘기기), 계약·연봉, 장비.

### 7. 업적과 경력 (kind: cr-log)

- 시즌별 연표 카드, 상 받은 시즌에는 시상 아이콘(awards.png: MVP·신인왕·홈런왕·골든글러브·우승·명예의 전당).

### 8. 대화 창 (kind: cr-event, 계약 제안, 인터뷰)

- 게임빌 "친구 지원" 창처럼: 말하는 사람 그림 + 이름 띠 + 말 + 고르는 단추(아이콘·효과 미리 보기).

### 9. 경기 고르기 (kind: cr-game)

- 대진 카드: 우리 팀 엠블럼 vs 상대 엠블럼, 구장, 오늘 내 타순(또는 선발 등판), 단추 세 개(직접 하기·맡기고 결과 듣기·건너뛰기).

### 10. 선수 만들기 (kind: cr-new-*)

- 이름 → 얼굴 고르기(12가지 바둑판, 새로 넣음) → 등번호(숫자판) → 타자·투수 → 포지션(야구장 그림 위 자리 누르기) → 유형(카드) → 팀(엠블럼 카드).
- 얼굴과 등번호는 저장 형식에 새 칸(c.face, c.num)으로 더하고, 옛 저장은 이름으로 정한 얼굴·번호를 씀.

## 순서

1. 화면 정의에 kind·key 붙이기, 가방을 첫 화면으로, 자원 줄 글자 안 보이는 문제와 용품점 이름 줄바꿈 고치기. (두 모드 시험)
2. 라커룸 첫 화면, 훈련, 가방, 선수 카드. (지금 있는 그림 + 얼굴 + 아이콘으로)
3. 마을 지도와 장소 안 화면. (마을 지도 그림이 오면)
4. 대화 창, 경기 고르기, 업적, 선수 만들기(얼굴·등번호).
5. 시험: tests/career.js(계산), e2e 육성 부분, tests/skin.js에 육성 한 바퀴(만들기 → 훈련 → 마을 → 장소 → 가방 → 경기) 더하기. main에 올림.

## 필요한 그림

- 마을 지도(세로 2:3, 장소 9곳을 3×3으로 놓아 자리를 정확히 잡음, 글자 없음)
- 라커룸 배경(3:2)
- 훈련 아이콘 10개(능력치 9가지 + 쉬기)
- 휴가지 배경(8:7)
- (있으면 좋음) 선수 얼굴을 더 크게: 지금 faces 원본에서 96픽셀로 다시 뽑으면 되므로 새 그림은 필요 없음
