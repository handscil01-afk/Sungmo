# 접근성 수동 확인 목록 (사람이 직접 해야 하는 것)

자동 시험(`tests/e2e.js`)은 키보드로 모든 설정 탭·두 자리 입력·결과 전달 방식·진동 뜻 화면이 동작하는지까지 확인합니다.
아래는 **실제 화면 낭독기·점자 단말기·진동 장치가 있어야만 확인되는 것**입니다. 확인한 날짜와 기기, 결과를 적어 주세요.

| # | 확인할 것 | 방법 | 기대 결과 | 결과 |
|---|---|---|---|---|
| 1 | 설정 탭 이동 | 설정을 열고 9번을 여러 번 누르기, 왼쪽·오른쪽 화살표 누르기 | 탭 이름이 "설정, ○○ 탭, N번째 탭 6개 중"으로 읽힘. 화살표를 눌러도 낭독기가 화살표를 가로채 읽기만 하지 않고 탭이 바뀜 | |
| 2 | 설정 값 바꾸기 | 탭 안의 항목을 번호로 고르기 | 바뀐 값만 "글자 크기 크게"처럼 한 번 읽힘 (전체를 다시 읽지 않음) | |
| 3 | 결과 전달: 소리와 글 | 중계 음성을 켜고 한 타석 진행 | 중계 음성이 결과를 말하고, 낭독기는 결과 글을 따로 읽지 않고 질문부터 읽음. 결과 글은 화면과 점자 단말기에서 한 줄씩 읽을 수 있음 | |
| 4 | 결과 전달: 소리만 | 위와 같이 | 결과 글이 화면에서 사라지고 질문과 선택지만 남음 | |
| 5 | 결과 전달: 글만 | 위와 같이 | 중계 음성이 결과를 말하지 않고 낭독기가 결과 글을 읽음 | |
| 6 | 진동 뜻 익히기 | 설정 → 조작·접근성 → 진동 뜻 익히기에서 1~8번 | 번호마다 다른 진동이 울리고 뜻을 말함. 스트라이크=짧게 1, 볼=길게 1, 안타=짧게 2, 장타=짧게 3, 홈런=길게·짧게·길게, 아웃=길게 2, 삼진=길게 3, 득점=짧게 3 뒤 길게 | |
| 7 | 경기 중 진동 | 진동을 켜고 한 경기 진행 | 6번과 같은 모양이 사건에 맞게 울림 (진동을 지원하지 않는 기기는 해당 없음) | |
| 8 | 두 자리 입력 | 선택지가 10개 넘는 화면(화면 보며 하기의 팀 고르기 등)에서 1, 0을 연달아 누르기 | 10번이 골라짐. 1만 누르고 기다리면 약 0.8초 뒤 1번이 골라짐 | |
| 9 | 송구 선택 | 정밀 모드로 수비하며 땅볼 | "어디로 던질까요?"가 읽히고 번호로 고를 수 있음. 6초 뒤 컴퓨터가 정하면 그 사실이 읽힘 | |
| 10 | 초점 순서 | Tab 키(또는 낭독기 이동)로 화면 훑기 | 질문 → 선택지 → 뒤로 순서 | |
| 11 | 점자 단말기 입력 | 명령 칸에 `11`처럼 두 자리를 적고 입력 | 11번이 골라짐 | |

## 알려진 한계
- 중계 음성과 조작 안내 음성이 겹칠 때 중계를 줄이는 것(덕킹)은 아직 하지 않았습니다.
- 볼카운트·주자를 색만이 아닌 글자·모양으로 함께 보여 주는 것은 화면 보며 하기 정리(Phase 4)에서 합니다.
