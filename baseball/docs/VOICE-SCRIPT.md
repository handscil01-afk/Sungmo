# 새 녹음 대본 (Phase 6)

코드는 이미 아래 아이디를 읽도록 되어 있어서, **녹음 파일(mp3)을 `voice/`에 넣고 `voice/index.json`의 `variants`에 아이디와 개수를 적으면 바로 나옵니다.** 녹음이 없는 줄은 건너뛰므로 일부만 먼저 받아도 됩니다.
녹음을 자르고 확인하는 방법은 `voice/README.md`와 `voice/check.html`을 따르세요.

## 1. 이닝 끝 해설 (해설위원, 차분~보통)
이닝이 끝나고 공수가 바뀔 때, 그 이닝의 기록(inningLog)에 맞는 한 줄만 말합니다. **실점한 이닝에는 "깔끔하게"를 말하지 않습니다.**

| 아이디 | 말 | 쓰는 때 |
|---|---|---|
| a_inning1 (있음) | 깔끔하게 이닝을 마무리합니다. | 삼자범퇴 (출루 없음) |
| a_inning2 (있음) | 실점 없이 막아 냅니다. | 점수는 안 났지만 주자가 나간 이닝 |
| a_inn_k | 삼진 세 개로 이닝을 끝냅니다! | 삼진 3개로 삼자범퇴 |
| a_inn_dp | 병살로 불을 끕니다. | 병살로 이닝이 끝남 |
| a_inn_lob | 아쉽습니다, 주자를 세 명이나 남겼습니다. | 잔루 3명 |
| a_inn_escape | 위기를 잘 넘깁니다. | 주자가 나갔지만 무실점 |
| a_inn_run1 | 한 점을 내주고 이닝을 마칩니다. | 1실점 |
| a_inn_runs | 두 점을 내주고 이닝을 마칩니다. | 2실점 |
| a_inn_big | 크게 무너진 이닝이었습니다. | 3실점 이상 |

각각 변형(이름-2, 이름-3)을 두 개쯤 받으면 덜 지루합니다.

## 2. 수비수 중계 (캐스터)
`pos_<포지션>_c`: "~가 잡았습니다." 포지션: P 투수, C 포수, 1B 1루수, 2B 2루수, SS 유격수, 3B 3루수, LF 좌익수, CF 중견수, RF 우익수 (9줄).
`thr_0~3`: "1루로 송구합니다." / "2루로" / "3루로" / "홈으로" (4줄).
아직 코드에는 `pos_*_c`와 `thr_*`만 연결되어 있습니다. 아래는 다음에 연결할 줄입니다.
- `pos_<포지션>_to` ("~ 앞으로", 9줄)와 `pos_<포지션>_at` ("~ 쪽으로", 9줄): 타구가 가는 방향 안내
- `thr_none` ("던지지 않습니다."), `thr_ask` ("송구 선택!")

## 3. 히트 앤드 런 (캐스터 2 + 해설 2)
"히트 앤드 런!", "주자 스타트!", 해설: "작전이 나왔네요.", "맞히면 한 베이스 더 갈 수 있습니다."

## 4. 함성 (선택: 줄 수 있다면)
탄식, 큰 환호, 끝내기 환호 효과음. 지금은 `cheer1`(안타)·`cheer2`(홈런) 한 벌만 있어서 크기만 조절합니다.

## 5. 해설 스타일 (hype)
`voice/index.json`에 `styles`를 더하고 같은 아이디의 다른 말투 녹음을 `voice/hype/<아이디>.mp3`에 두면, 설정의 "해설 스타일: 신나게"가 나타납니다.
```json
{ "variants": { "...": 1 }, "styles": { "hype": { "r_hit1": 1, "a_hr1": 2 } } }
```
스타일에 없는 줄은 기본(차분) 녹음으로 나옵니다. `a_` 해설 줄과 `r_` 결과 줄부터 받으면 효과가 큽니다.
