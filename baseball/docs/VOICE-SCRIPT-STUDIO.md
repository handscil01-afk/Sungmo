# 새 녹음 대본 전체 (AI Studio 음성 만들기용)

이 파일을 위에서부터 묶음 하나씩 AI Studio에 붙여 넣어 녹음 파일을 만듭니다. 자세한 순서는 맨 아래 "하는 순서"를 보세요.

- **묶음 이름**(N1, P1 …)은 나중에 녹음 파일을 자를 때 씁니다.
- 한 묶음은 **같은 목소리 하나**로 읽어야 합니다. 캐스터(C) 묶음은 캐스터 이하늘, 해설(A) 묶음은 해설위원 강태산의 목소리(이전에 쓴 것과 같은 Voice)를 고르세요.
- 줄 수: 기본 55줄(필수), 신나게 말투 155줄(선택).

| 묶음 | 화자 | 줄 수 | 내용 |
|---|---|---|---|
| N1 | 해설 | 6 | 이닝 끝 해설 (무실점) |

## 1. 필수 녹음 (N1~R2)

### N1 · 이닝 끝 해설 (무실점)

- **Speaker/Voice**: 해설위원 강태산 (캐스터와 다른 목소리: 차분한 40대 남성, 이전 해설 녹음과 같은 Voice)
- **Style 칸**: 한국어 야구 해설위원, 차분한 40대 남성. 차분하고 안정적인 해설위원 목소리. 이닝이 깔끔하게 끝났을 때의 평가. 문장마다 2초 쉬고 다음 문장을 읽음.
- **본문 칸** (아래 줄을 그대로 붙여 넣기, 줄 사이는 빈 줄):

```
삼진 세 개로 이닝을 끝냅니다!

세 타자를 모두 삼진으로 잡았습니다. 대단한 이닝이었어요.

병살로 불을 끕니다.

병살타로 위기를 벗어나네요. 투수에게 큰 도움이 됩니다.

위기를 잘 넘깁니다.

주자가 나갔지만 실점 없이 막아 냅니다. 집중력이 좋았어요.
```

아이디 순서: `a_inn_k`, `a_inn_k-2`, `a_inn_dp`, `a_inn_dp-2`, `a_inn_escape`, `a_inn_escape-2`

## 하는 순서

1. AI Studio(Gemini 음성 만들기)에서 위 묶음 하나를 엽니다. Style 칸에 "Style 칸" 내용을, 본문 칸에 코드 상자 안의 글을 붙여 넣고, Voice는 표시된 화자와 같은 것을 고릅니다.
2. 만든 소리를 파일(wav 또는 mp3)로 저장합니다. 묶음 하나가 파일 하나입니다. 문장 사이에 2초 정도 쉬는 소리가 들어 있어야 자를 수 있습니다.
3. 저장소에서 아래 명령으로 문장마다 자릅니다(묶음 이름=파일 경로를 여러 개 한꺼번에 적을 수 있음). 자르면 `voice/` 폴더에 mp3가 만들어지고 `voice/index.json`에 자동으로 적힙니다. `hype/`로 시작하는 줄은 `voice/hype/`에 들어갑니다.
   ```
   python3 tools/voice3_cut.py N1=N1.wav N2=N2.wav P1=P1.wav
   ```
4. 문장 수와 잘린 조각 수가 다르면 그 묶음은 건너뛰고 이유를 알려 줍니다(문장을 빠뜨렸거나 두 번 읽은 경우). 그 묶음만 다시 만들면 됩니다.
5. `voice/check.html`을 열어 소리가 맞는지 듣습니다. 올린 뒤에는 앱을 새로 고침하면 새 소리가 나옵니다.

## 코드에 이미 연결된 것과 아닌 것
- 연결됨: `a_inn_*`(이닝 끝), `pos_*_c`(누가 잡았는지), `thr_0~3`(송구), `pos_*_to`와 `pos_*_at`(타구 방향), `thr_ask`와 `thr_none`, `c_hitrun*`와 `a_hitrun*`, 신나게 말투(`hype/`).
- 녹음 파일이 없는 줄은 그냥 건너뛰므로 일부만 먼저 만들어도 됩니다.
