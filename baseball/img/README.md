# 도트 그림 파일 (화면 보며 하기)

`js/gfx.js`는 이 폴더의 그림이 있으면 그것을 쓰고, 없으면 코드로 그린 그림을 씁니다.
GPT가 만든 원본은 `python3 -I baseball/tools/sprites.py <원본 폴더>`로 바꿉니다. 원본 폴더의 `sprites.json`에 파일마다 종류(bg·sprite·banners), 잘라 낼 범위, 체크무늬 배경 여부, 줄 수, 목표 높이를 적으면, 배경을 지우고 동작 칸을 나눠 같은 비율로 줄인 뒤 `img/`와 `index.json`(칸 크기·칸 수·줄 수)을 만듭니다.
투수 그림은 세 줄(오버핸드·사이드암·언더핸드)이고, 투수마다 폼이 정해집니다. 왼손 투수·왼손 타자는 게임이 좌우를 뒤집어 그립니다.
`sw.js`의 캐시 목록과 버전도 함께 고칩니다.

공통 규칙
- 실제 크기(아래 표)의 PNG, 배경은 투명(배경 그림 두 장만 빼고). 흐린 테두리(안티에일리어싱) 없이 색이 딱 떨어지게.
- 팀 색이 들어갈 자리(모자, 유니폼 줄, 양말)는 순수한 자홍색 `#FF00FF`로 칠함. 게임이 팀 색으로 바꿔 칠함.
- GPT가 만든 큰 그림(예: 4배 크기)은 가장 가까운 점 방식(nearest)으로 줄이고 색 수를 줄여서 넣음.

|---|---|---|
| bg-pitch.png | 256×224 | 포수 뒤에서 본 야구장. 위 18픽셀은 점수판이 덮음. 마운드 가운데 (128,104), 홈플레이트 (128,204) |
| bg-field.png | 256×224 | 위에서 본 야구장. 홈플레이트 (128,210), 1미터 = 1.3픽셀(가운데 담장 약 120미터 → 위쪽 끝 근처) |
| pitcher.png | 128×48 | 32×48 네 칸: 준비 · 다리 들기 · 던지기 · 던진 뒤. 앞모습. 발끝이 칸 아래쪽 |
| batter.png | 128×48 | 32×48 네 칸: 준비 자세 · 스윙 · 스윙 뒤 · 번트. 뒷모습, 오른손 타자(왼손은 게임이 뒤집음) |
