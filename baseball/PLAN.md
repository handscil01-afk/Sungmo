# 손잡다 야구: 만드는 계획

시청각장애인이 화면을 보지 않고도 할 수 있는 "듣고 고르는 확률 야구"입니다. 처음 대상은 센터장님(아이폰 보이스오버, 한소네, 리보 키보드)입니다.

## 원칙

- 모든 화면은 "질문 하나 + 번호 붙은 선택지"입니다. 단추(보이스오버 두 번 탭), 숫자 키(리보 숫자판), 명령 칸(한소네 점자 입력) 가운데 무엇으로 골라도 똑같이 동작합니다.
- 결과는 한 줄씩 짧은 문장으로 남깁니다(점자 단말기로 한 줄씩 읽기 좋게). 그림 문자는 쓰지 않습니다.
- 단추로 고르면 결과 글로 초점을 옮기고, 키로 고르면 초점은 그대로 두고 알림 칸(aria-live)으로 읽어 줍니다.
- 경기 계산(engine.js)은 화면과 분리합니다. 상태와 난수 씨앗을 모두 경기 상태 안에 두어, 온라인에서 방장 기기가 계산하고 상태를 보내기 쉽게 합니다.

## 1단계 (완료): 혼자·둘이(한 기기)·관전

- 간단 모드: 타석마다 한 번 고르고 1~100 주사위로 결정. 선택지마다 안타·홈런·삼진 확률 표시.
- 정밀 모드: 공마다 구종(투수별 3~4개) → 코스(스트라이크 존 9칸) → 붙이는 정도(존 안쪽·구석·빼기) → 세기(전력·보통·힘 빼고, 예상 구속 표시).
- 타자: 치기·강하게·맞히기·지켜보기·번트·도루·노림수(직구/변화구).
- 결과에 영향: 타자(컨택·파워·선구안·스피드·수비·성향), 투수(구속·제구·구위·체력·구종 완성도), 컨디션, 팀 스타일 6가지, 바람(방향·세기), 수비 위치(내야·외야 전진/보통/후진), 볼카운트, 타이밍(같은 공 반복, 빠른 공 뒤 느린 공), 투구 수에 따른 피로, 실투, 몸에 맞는 공, 실책, 병살, 희생 플라이.
- 볼인데도 헛스윙(유인구), 한가운데인데도 지켜봄, 잘 맞았지만 담장 앞에서 잡힘, 바람 덕에 간신히 넘어가는 홈런이 모두 나옵니다.
- 맡기기(이번 공·타석·이닝), 투수 교체, 고의 볼넷, 판정 과정(주사위) 보기, 이어하기.
- 효과음(파일 없이 합성), 진동(안드로이드), 글자 크기 4단계, 화면 색 3가지(어두운 고대비·밝은·노랑 바탕).
- 시험: `node baseball/tests/sim.js` (컴퓨터끼리 수백 경기, 수치·규칙 확인), `node baseball/tests/e2e.js` (Playwright로 화면에서 끝까지 진행).

## 2단계 (완료): 온라인 대전 + 채팅 + 음성 대화

- 방 만들기 / 방 코드(숫자 4자리, 숫자판·단추·명령 칸으로 입력) / 초대 링크(`?room=1234`)로 들어가기.
- Firebase Realtime Database(운동회 앱과 같은 `handscil-sports` 프로젝트, 경로 `baseball/rooms/{코드}`). 방장 기기가 경기를 계산하고 상태를 보냄(난수 씨앗·긴 기록은 빼고 약 6KB).
- 공정성: 손님 선택은 `act`에 쓰고 방장만 읽음. 방장 선택은 서버에 올리지 않음. 방장의 지난 공 의도(lastSel)와 노림수도 보내지 않음. 방장 기기는 손님 선택의 차례·값을 확인.
- 채팅: 명령 칸 글(선택지 이름과 같지 않으면 채팅) + 빠른 문구. 받은 채팅 읽어 주기(설정).
- 음성: WebRTC 직접 연결(서버 한도를 쓰지 않음). 통화·무전기 방식을 기기마다 고름. 무전기 시작음과 "상대 말하는 중" 표시는 데이터 채널로 주고받음.
- 끊김: 접속 표시(hb)로 상대에게 알림, 같은 기기에서 "방 다시 들어가기"로 이어 하기.
- 남은 일: 직접 연결이 안 되는 망을 위한 TURN 서버(필요하면 무료 TURN을 `TURN_SERVERS`에 넣기), 상대가 오래 안 돌아오면 컴퓨터가 대신 고르기.

## 3단계 (완료): 감독 모드

- 공 하나하나는 선수(컴퓨터)가 하고, 감독은 경기 전 타순·벤치·선발 투수를 정하고(G.pre → beginGame), 경기 중에는 타석마다 작전만 지시(playManager: 작전에 맞춰 aiPitch·aiBat가 공마다 고름).
- 작전: 공격(맡기기·적극적·신중·번트·도루·히트 앤드 런·대타·대주자), 수비(맡기기·정면 승부·어렵게 승부·고의 볼넷·투수 교체·수비 위치). 벤치 4명.
- 중요한 순간(mgrImportant)에만 묻고 나머지는 mgrAuto가 진행, 요약 중계("타자: 결과"). 설정으로 매 타석·공 하나하나.
- 같은 구조(타석마다 양쪽이 몰래 고름)라 혼자·둘이·관전·온라인 감독 대결이 모두 됨. 컴퓨터 감독(aiOrderDef·aiOrderOff·aiManageOff).

## 4단계 (완료): 비디오 판독, 10개 팀, 구장

- 팀 10개(가상, "도시 + 영문 애칭"), 팀 key는 저장 호환을 위해 유지. 구장(PARKS): 담장 거리·높이, 인조 잔디, 파울 지역, 돔, 바람 성향, 간단 모드 홈런·3루타 배율.
- 비디오 판독(G.review → resolveReview): 도루·1루 승부·담장 끝 타구가 아슬아슬하면(주사위가 기준에 가까우면) 원심을 정하고, 손해를 본 팀이 신청 여부를 고름. 팀당 2번, 번복되면 유지. 컴퓨터는 aiChallenge.
- 간단 모드 '공 하나씩'(센터장님 의견): 한 번 고르면 공 하나, 볼카운트·참기·헛스윙·파울 주사위.

## 5단계 (완료): 리그

- 10개 팀 리그, 내 팀 고르기, 시즌 길이 18(기본)·36·72·144경기. 선수는 시즌 내내 같은 사람, 컨디션은 날마다 바뀜. 선발 5인 로테이션, 불펜 연투 피로.
- 내 팀 경기는 간단·정밀·감독 모드 가운데 골라서 하고, 나머지 경기는 즉시 결과만.
- 순위표(승·패·무·승률·게임 차·최근 10경기), 개인 기록(타율·홈런·타점·안타·도루 / 승·패·세이브·홀드·평균자책점·탈삼진). 승리·패전·세이브 투수 규칙.
- 포스트시즌(KBO 방식): 와일드카드 결정전(4위 1승 안고 시작) → 준플레이오프(5전 3선승) → 플레이오프(5전 3선승) → 한국시리즈(7전 4선승). 시상(MVP, 신인왕, 타이틀).
- 이 기기에 저장, 백업 파일 내보내기·불러오기.
- 구현: js/league.js(리그 계산, Node 시험 tests/league.js), js/league-ui.js(화면). 컴퓨터 경기는 감독 모드 계산(leagueSim). 능력치가 아주 높을 때 효과를 누그러뜨림(soft)으로 시즌 기록이 KBO와 비슷하게 나옴.

## 6단계 (완료): 기록실과 명예의 전당

- 통산 기록 순위, 시즌 최다 기록, 우승 팀 연표, 내 감독 기록. 대기록 알림(사이클링 히트, 노히트 노런, 퍼펙트게임, 통산 100호 홈런).
- 여러 시즌: 나이에 따른 성장·하락, 은퇴, 신인 입단. 은퇴 선수 가운데 기준을 넘으면 명예의 전당 헌액.

## 7단계: 선수 육성 모드

- 내 선수 한 명(투수 또는 타자)을 만들어 신인으로 입단. 경기에서는 내 선수 차례만 직접 하고 나머지는 빠르게 진행.
- 경기 사이 훈련(타격·수비·주루·체력)과 휴식, 경험치로 성장. 2군 → 1군 → 주전 → 올스타·타이틀·우승 → 은퇴·명예의 전당. 슬럼프·부상·인터뷰 이벤트.

## 8단계: 덧붙이면 좋을 것들

- 장내 아나운서 타석 소개·관중 소리, 우천 취소·콜드게임, 하이라이트 다시 듣기, 라디오 중계 모드, 온라인 리그, 클라우드 저장, 올스타전·홈런 더비.

## 그다음에 더할 만한 것

- 감독 모드 다듬기: 수비 교체(대수비), 투수의 투구 지침을 이닝 단위로 정하기, 상대 타자 분석(오늘 결과·약점 코스).

- 우리 센터 이름으로 팀·선수 만들기(이용자 이름, 별명, 능력치 직접 정하기).
- 시즌(여러 경기) 기록, 개인 성적, 순위표.
- 작전 더하기: 히트 앤드 런, 견제구, 피치아웃, 폭투·포일, 대타.
- 관중 소리·응원가, 해설 길이 고르기(짧게·자세히), 점자 단말기용 아주 짧은 문장 모드.
- 경기 결과를 카카오톡·문자로 공유하기.
