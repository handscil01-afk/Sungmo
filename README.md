## 성경 부루마블 (`bible-marble/`)

주사위를 굴려 성경의 땅을 여행하고 말씀 퀴즈를 푸는 2~4인 보드게임입니다. 설치 없이 브라우저에서 열리고, 한 번 연 뒤에는 인터넷 없이도 열립니다(함께하기 제외).

- 보드 판 세 가지: 신구약(우르에서 바울의 선교까지), 구약(에덴 동산에서 출발), 신약(베들레헴에서 출발). 판의 시대에 맞는 퀴즈와 말씀 카드만 나옵니다.
- 말씀 퀴즈 약 260문항(객관식·주관식). 컴퓨터는 객관식만 풀고, 주관식은 소리 내어 답한 뒤 진행자가 정답·오답을 누릅니다.
- 객관식을 틀리면 나머지 모두(컴퓨터 포함)가 동시에 답하고 맞힌 사람끼리 상금 전부를 나누는 "객관식은 모두 도전", 주관식을 다른 팀이 이어서 풀 수 있는 "다른 팀에게 기회"(상금 절반) 규칙, 객관식·주관식 따로 정하는 퀴즈 제한 시간, 컴퓨터 차례 퀴즈를 직접 넘기기 등 설정을 탭으로 나누어 고를 수 있습니다.
- 사람 플레이어마다 화면 주사위와 실물 주사위(나온 숫자 입력)를 고르고, 컴퓨터는 자동으로 굴립니다. 플레이어 색과 동물 캐릭터도 바꿀 수 있습니다.
- 머리줄의 되돌리기 버튼으로 사람이 한 선택을 하나씩 되돌립니다. 주사위 눈과 문제는 그대로 유지됩니다.
- 휴대폰 세로·가로, 태블릿, PC, TV 크기에 맞춰 보드와 양옆 상황판 크기가 바뀝니다. 설정의 글자 크기로 더 크게 볼 수 있습니다.
- 콘텐츠 관리: 퀴즈·보드 판·말씀 카드를 목록에서 켜고 끄고, 고치고, 추가·삭제할 수 있습니다. 엑셀(.xlsx)·CSV로 내보내고 불러올 수 있고, 잘못된 줄은 몇째 줄인지 알려 줍니다. 전체 백업(.json)도 됩니다.
- 성경 본문: 가지고 있는 개역개정 텍스트 파일을 콘텐츠 관리 → 성경 본문에서 불러오면, 게임 속 📖 구절을 누를 때 본문이 큰 글씨로 나옵니다. 본문은 그 기기 안(IndexedDB)에만 저장되고 이 저장소에는 들어 있지 않습니다.
- 함께하기(여러 기기): 방을 만들 때 진행 방식을 먼저 고릅니다.
  - **플레이어 모드**: 방장도 플레이어 한 명으로 참가합니다. 각자 자기 자리만 조작할 수 있고(방장도 남의 주사위·선택을 대신할 수 없음), 주관식은 각자 입력하면 게임이 채점합니다(띄어쓰기·공백·문장부호 차이는 허용). 공평하게 하려고 되돌리기는 쓰지 않습니다.
  - **중계 모드**: 방장은 진행자·심판입니다. PC에서는 "게임 화면 창"을 따로 띄워 TV(확장 모니터)에 보여 주고, 진행자 창에서 정답을 보며 판정합니다. 태블릿에서는 한 화면에서 진행하고, 정답은 태블릿에 보이지 않습니다(필요하면 진행자 휴대폰을 PIN으로 "진행자 리모컨"으로 연결해 정답 확인·판정). 참가자 휴대폰에는 내 상황판과 다른 플레이어 목록이 나옵니다. 휴대폰이 없는 팀은 "진행자 조작" 자리로 둘 수 있습니다.
  - 자리마다 고유 ID와 열쇠가 있어서, 새로고침·앱 종료·잠깐 끊김 뒤에도 같은 자리로 돌아갑니다. 방장이 나갔다가 "이어하기"를 누르면 같은 방 코드로 방이 다시 열립니다. 방 코드는 게임판 가운데와 설정 → 멀티플레이에서 보고 복사할 수 있습니다.
  - 게임 중 새 사람이 들어오면 방장에게 "컴퓨터 자리를 넘겨줄지" 묻고, 참가자가 나간 채 돌아오지 않으면 "컴퓨터로 대체할지"(난이도 선택) 묻습니다. 자리를 바꿔도 위치·달란트·땅·건물·카드는 그대로 이어집니다.
  - 함께하기를 누르면 방 목록이 나옵니다. 방마다 방 이름, 방장, 진행 방식, 인원(예: 1/4), 공개 여부, 보드 판, 난이도, 라운드, 게임 중인지가 보입니다. 방을 만들 때 방 이름과 공개·비공개를 정하고, 비공개 방은 비밀번호를 자동으로 만들거나 직접 정합니다(비밀번호는 서버에 올리지 않고 방장 기기만 확인).
  - 진행자 리모컨(중계 모드, PIN 필요): 게임판 대신 지금 상황과 정답·해설을 미리 보여 주고, 판정·계속하기, 플레이어 관리(컴퓨터 대체·난이도·진행자 조작), 달란트 직접 조정, 되돌리기, 잠시 멈춤을 할 수 있습니다.
  - 방 공유하기를 누르면 카카오톡·문자 등으로 링크를 보낼 수 있고, 받은 사람은 이름만 적으면 바로 들어옵니다. 다른 브라우저로 다시 들어와도 같은 이름이면 원래 자리로 돌아갑니다.
  - 대기실에서는 정한 인원까지 컴퓨터로 채워 두고, 사람이 들어오면 컴퓨터 한 자리를 넘겨받습니다(최대 4명). 나간 사람이 잠시 돌아오지 않으면 그 자리는 컴퓨터로 채우고, 인원을 줄여도 들어와 있는 사람은 내보내지 않습니다.
  - 연결: `js/firebase-config.js`에 Firebase 설정이 있으면 Firebase Realtime Database를 중계 서버로 씁니다(아이폰·카카오톡 앱 안 브라우저·LTE에서도 안정적). 설정이 비어 있으면 PeerJS로 기기끼리 직접 연결합니다. PC 중계 모드의 게임 화면 창은 같은 PC 안에서 연결되므로 인터넷이 없어도 됩니다.

### Firebase 설정 (함께하기 연결)

1. https://console.firebase.google.com 에서 프로젝트를 만듭니다(애널리틱스 끔).
2. Authentication → 로그인 방법 → **익명**을 켭니다.
3. Realtime Database → 데이터베이스 만들기(싱가포르 asia-southeast1, 잠금 모드) → 규칙 탭에 아래 규칙을 붙여 넣고 게시합니다.
4. 프로젝트 설정 → 내 앱 → 웹 앱 등록 → `firebaseConfig` 값을 `bible-marble/js/firebase-config.js`의 `window.FIREBASE_CONFIG`에 넣습니다. 이 값은 공개되어도 되는 식별자이고, 보안은 아래 규칙이 맡습니다(방장만 방 안의 우편함을 읽고, 각 기기는 자기 우편함만 읽고 씀).

```json
{
  "rules": {
    "lobby": {
      ".read": "auth != null",
      "$code": {
        ".write": "auth != null && (!data.exists() || data.child('hu').val() === auth.uid)",
        ".validate": "!newData.exists() || (newData.child('hu').val() === auth.uid && newData.child('title').isString() && newData.child('title').val().length <= 40)"
      }
    },
    "rooms": {
      "$code": {
        "meta": {
          ".read": "auth != null",
          ".write": "auth != null && (!data.exists() || data.child('host').val() === auth.uid)",
          ".validate": "!newData.exists() || newData.child('host').val() === auth.uid"
        },
        "hp": {
          ".read": "auth != null",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid"
        },
        "in": {
          ".read": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          "$id": {
            ".write": "auth != null && !data.exists() && newData.child('f').val() === auth.uid",
            ".validate": "newData.child('s').isString() && newData.child('s').val().length < 8000"
          }
        },
        "q": {
          "$uid": {
            ".read": "auth != null && auth.uid === $uid",
            ".write": "auth != null && (auth.uid === $uid || root.child('rooms').child($code).child('meta/host').val() === auth.uid)"
          }
        },
        "pr": {
          ".read": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          ".write": "auth != null && root.child('rooms').child($code).child('meta/host').val() === auth.uid",
          "$uid": {
            ".write": "auth != null && auth.uid === $uid"
          }
        }
      }
    }
  }
}
```
- 게임 중에는 머리줄을 없애고 게임판을 최대한 크게 보여 줍니다. 게임판 가운데의 ↩️(되돌리기, 확인 후 실행)와 ⚙️(설정) 버튼만 남기고, 설정은 게임·멀티플레이·게임 규칙·퀴즈·컴퓨터·화면·소리·콘텐츠로 나뉩니다.
- 주사위 차례가 되면 굴릴 사람의 화면에 큰 버튼만 나오고, 굴린 주사위는 모든 기기에서 화면 전체에 크게 굴러 결과가 또렷하게 보입니다(컴퓨터 주사위 포함). 말씀 카드·이벤트는 사람 차례에는 확인을 눌러야 넘어가고, 컴퓨터 차례에는 남은 시간 막대와 함께 5초 동안 보여 줍니다.
- 산 땅은 주인 색 배경 그대로이고, 건물을 지으면 칸 위에 장막(커튼이 드리운 모양)·집(지붕)·성(뾰족한 성 지붕) 장식과 굵은 테두리가 생깁니다.
- 가진 땅은 상황판에 카드 패처럼 부채꼴로 놓이고, 카드를 누르면 꺼내어 크게 보여 줍니다.
- 통행료·십일조처럼 돈이 오가면 10 단위는 동전, 100 단위는 지폐가 낸 사람에게서 받는 사람에게 날아가고, 낸 쪽에는 빨간 −금액, 받는 쪽에는 초록 +금액이 크게 뜹니다.
- 돈이 모자라면 "어느 땅을 파시겠습니까?"라고 묻고, 고른 땅을 건물과 함께 통째로 반값에 팝니다(건물만 따로 팔지 않음). 다 팔아도 모자라면 파산합니다.
- 라운드 수는 10·20·30 가운데 고르거나 직접 숫자를 넣을 수 있고, "파산까지"를 고르면 한 명만 남을 때까지 계속합니다.
- 불수레(원하는 칸으로) 칸에서는 게임판을 보며 날아갈 칸을 고릅니다.
- 캐릭터에 기기에 있는 사진을 넣을 수 있습니다. 동그란 점선 안만 선명하게 보이고, 두 손가락으로 확대·축소·회전해서 맞춥니다. 사진은 작게 줄여 기기 안에만 저장하고, 함께하기에서는 같은 방 기기들에게만 전달합니다.
- 소리 설정에서 잔잔한 1분짜리 배경 음악(끊김 없이 반복)을 켜고 끄고 크기를 고를 수 있습니다. 참가자 휴대폰에서는 처음에 꺼져 있습니다.
- 설정 → ✨ 추가 기능에서 아래 기능을 하나씩 켜고 끕니다.
  - 🃏 성경 인물 카드 수집: 퀴즈·암송 미션을 맞히거나 헌금함 칸에 가면 인물 카드를 받습니다. 인물마다 한 번 쓰는 능력(다윗 통행료 면제, 모세 광야 탈출, 에스더 원하는 칸 이동, 요셉 200 받기, 엘리야 헌금함 절반, 룻 모두에게서 30씩)이 있고, 여섯 명을 모으면 500 달란트를 받습니다.
  - 🤝 플레이어끼리 땅 거래: 주사위를 굴리기 전에 땅과 달란트를 바꾸자고 제안하고, 상대가 받아들이면 바로 바뀝니다. 컴퓨터는 받는 쪽이 넉넉히 이득일 때만 받아들입니다.
  - 📜 말씀 암송 미션 칸: 퀴즈 칸 하나가 암송 미션 칸이 되어 구절의 빈칸 채우기 문제가 나옵니다. 사용자가 불러온 성경 본문이나 직접 넣은 구절만 쓰고, 저장소에는 구절 주소만 있습니다.
  - ⏱ 시간 제한: 정한 시간이 지나면 그 라운드까지만 하고 끝냅니다. 진행자가 멈춘 동안은 시간이 가지 않습니다.
  - 👥 팀전: 함께하기에서 한 자리에 여러 기기가 팀원으로 들어와, 팀원 휴대폰 어느 것으로든 그 팀 차례를 조작합니다.
  - 🎤 진행자 즉석 문제: 진행자(중계 모드의 리모컨·진행자 화면, 한 기기 게임의 설정)가 입력한 문제를 다음 차례 사람이나 모두에게 냅니다.
  - 🏆 게임 기록·명예의 전당, 🎉 승리 연출(폭죽·시상대)과 결과 이미지 저장·보내기.
- 플레이어 말은 칸 안쪽 가장자리에 놓여 땅 이름과 통행료를 가리지 않고, 같은 칸에 여럿이 있으면 나란히 놓입니다.
- 홈 화면 설치, 전체화면, 화면 꺼짐 방지, 자동 저장과 이어하기를 지원합니다.

파일 구성: `index.html`(화면 틀), `css/game.css`, `js/`(엔진·AI·화면·통신), `js/data/`(기본 보드·퀴즈·카드), `vendor/peerjs.min.js`(MIT), `vendor/firebase-*-compat.js`(Apache-2.0, 함께하기를 쓸 때만 불러옴), `sw.js`(오프라인).

## 난장이의 피아노 교실 (`piano/`)

피아노를 처음 치는 사람이 코드(화음)를 차근차근 익히는 연습 앱입니다. 팬플룻 교실과 같은 모양의 PWA로, `piano/` 폴더를 그대로 웹에 올리면 홈 화면에 설치할 수 있습니다.

- 다섯 단계: 첫걸음(건반·손가락·반음) → 기본 코드(C, Cm) → 7화음 → 색깔 코드(sus·dim·aug) → 활용(자리바꿈, 코드 진행, 노래 반주)
- 코드 이름은 정석 표기로 보여 줍니다. 예: Cm = 도 · 미♭ · 솔 (미♭이 레♯과 같은 건반이라는 안내를 함께 표시)
- 입력 방법 세 가지를 함께 쓸 수 있습니다.
  - 화면 건반: ‘콕콕’(하나씩 켜기) / ‘꾹’(누르는 동안) 방식
  - 디지털피아노 MIDI 연결 (안드로이드 크롬, PC 크롬·엣지)
  - 마이크: 진짜 피아노 소리를 듣고 여러 음을 함께 판정 (https 주소나 설치한 앱에서 동작)
- 연습: 코드 원리 배우기, 건반 찾기, 반음·온음 세기, 코드 짚기, 코드 이름 맞히기, 귀로 맞히기, 코드 진행(기다려 줘요 / 박자대로, 가까운 자리바꿈 추천), 노래 반주(작은 별, 환희의 송가, 생일 축하 노래, 징글벨, 어메이징 그레이스)
- 그 밖에: 누른 건반의 코드 이름 알아보기, 코드 사전, 메트로놈, 연습 기록과 코드별 실력, 기록 파일 보관
- 가로 화면 우선 배치: 위쪽은 문제 카드와 단추, 아래쪽은 큰 건반. 보이는 흰 건반 수는 가로·세로 화면마다 따로 정할 수 있습니다 (기본: 가로 약 한 옥타브 반).
- 지연 시간 보정: 듣는 장치(스피커, 블루투스 이어폰 등)마다 화면 터치 지연과 피아노(MIDI·마이크) 지연을 재서 ‘박자대로’ 판정에서 빼 줍니다.
- 처음 열면 홈 화면 설치 방법을 안내합니다 (안드로이드 크롬은 바로 설치, 아이폰·삼성 인터넷은 순서 안내).

## 명찰 만들기 (`name-badge/`)

행사용 양면 명찰(목걸이 케이스, 기본 125×90mm)과 직원용 접는 비상연락망을 만들어 A4에 인쇄하는 PC용 도구입니다. 파일(`index.html`) 하나로 되어 있어 PC에서 파일로 열어도 동작하고, 외부 라이브러리는 쓰지 않습니다.
- 명단: 엑셀(.xlsx)·CSV를 여러 개 차례로 불러옵니다. 파일마다 시트·머리글 줄을 고르고 열마다 쓰임(이름·구분·소속·연락처·짝 이름·짝 연락처·담당직원·쓰지 않음)을 고릅니다. 구분 열이 없으면 “이 파일은 모두 ○○”로 정하고, 구분 값(‘활동지원사’ 등)은 앱 구분에 자동 연결합니다. 열 설정은 머리글 이름 기준으로 기억합니다. 붙여넣기(이용인·활지사 자동 구분)와 표에서 바로 고치기, 이용인↔활지사 짝·담당직원 지정, 구분 추가·이름 바꾸기를 지원합니다.
- 앞면: 이름·소속·구분 띠·행사명·로고(위치·크기), 글씨 크기·글꼴, 구분별 테두리 색·두께. 이름이 길면 칸에 맞게 줄어듭니다.
- 뒷면: 구분별로 제목·안내 문구·짝 연락처·담당직원·행사 직원 연락처·행사 개요(시간표)·자유 문구를 체크로 넣고 뺍니다. 넘치면 글씨를 줄이고 7pt 아래로 내려가면 경고합니다.
- 접는 비상연락망: 명찰 크기 칸을 이어 붙인 한 장(칸 사이 접는 점선, 칸 번호)으로 인쇄합니다.
- 인쇄: A4 세로·가로 자동 선택, 양면(긴 쪽·짧은 쪽 넘김) 뒷면 반전 배치, 앞뒤 어긋남 보정, 재단 점선·눈금.
- 이름·연락처는 브라우저에 저장하지 않고 “명단 파일(.json)”로 저장·불러옵니다. 문구·색·크기·로고 같은 설정은 자동 저장되고 “설정 파일(.json)”로도 저장·불러올 수 있습니다.
- 홈 화면 설치·전체화면·오프라인 실행을 지원합니다.

## 쿠팡 비교견적 도우미 (`coupang-compare/`)

물품구입비 기안의 비교견적을 만들 때 쓰는 PC 크롬 템퍼몽키 스크립트입니다. 쿠팡 장바구니 물품을 기준으로 11번가·G마켓 검색 결과의 후보를 보여 주고, 사용자가 상품과 옵션을 고르면 수량을 맞춰 장바구니에 담고 금액을 기록합니다. 마지막에 세 쇼핑몰 금액 비교표를 복사할 수 있고, 장바구니를 캡처(영역 직접 지정 가능)해 견적서로 씁니다. 3.3부터는 요약표에 ‘전체 할인금액’(장바구니 쿠폰 등)과 ‘합계(할인 반영)’ 줄이 생기고(서류에도 반영), 서류의 지출처를 쿠팡 하단 사업자 정보로 채우며, 11번가·G마켓을 두 창에서 동시에 진행할 수 있습니다(끄면 차례로 진행). 3.2부터는 쿠팡 수량이 바뀌면 ‘수량 변경 반영’으로 기록을 고치고, ‘다시 담기’로 11번가·G마켓 장바구니를 기록한 상품·옵션 그대로 다시 채웁니다. 3.1부터는 ‘서류 만들기’로 기안·산출기초조사서·견적서·물품검수조서를 한 hwpx 파일로 만듭니다(`hwpx-builder.js`). 구매·결제 버튼은 누르지 않습니다. 홈 화면 설치용 앱이 아니라서 설치 안내 페이지(`index.html`)와 스크립트(`coupang-compare.user.js`)만 둡니다.

## 가을운동회 점수판 (`sports-day/`)

제5회 손잡다 가을운동회(10월 30일)에서 여러 기기로 함께 쓰는 점수판입니다. 야외 대낮에도 잘 보이도록 밝은 바탕에 진한 글씨, 큰 버튼을 씁니다.

- **역할**: 한 기기에 여러 역할(감독·심판·기록 도우미·계시원·안내판·방송 권한)을 함께 줄 수 있고, 역할마다 화면 위쪽 탭으로 오갑니다. 예) 이소흔: 청팀 감독 + 후리볼 심판.
- **담당자 명단**: 마스터가 '역할' 메뉴에서 이름과 맡을 역할을 미리 등록해 두면, 각 기기 첫 화면에서 이름만 눌러 바로 그 역할로 들어옵니다. **봉사자 자리**(예: 투호 기록 도우미, 줄달리기 계시원)는 여러 명이 같은 자리를 고르고 각자 이름을 적습니다. 명단에 있는 이름을 직접 적어서 들어와도 그 역할로 들어옵니다. 명단에 없는 사람은 이름을 적고 들어오면 마스터가 역할을 정해 줍니다.
  - **이름 = 로그인**: 같은 이름으로 다른 브라우저·앱에서 다시 들어오면 가장 최근에 들어온 기기만 남기고 예전 기기는 목록에서 지우며, 역할도 새 기기로 넘겨줍니다(마스터 기기가 켜져 있을 때 자동 정리).
  - **기록 도우미**: 맡은 종목 점수를 심판과 똑같이 입력합니다. **계시원**: 큰 초시계로 시간을 재서 '청·홍 기록 보내기'를 누르면 심판 화면 기록 칸이 채워지고, 심판이 확인한 뒤 저장합니다.
  - **마스터**(비밀번호 필요): 모든 종목 진행, 출전 순서, 현황판, 접속자·역할 지정, 명단·팀 이름·점수 설정, CSV 내려받기. 다른 기기에 마스터 권한을 줄 수도 있습니다.
  - **심판**(맡은 종목만 보임, 여러 종목 가능): 단체전은 지금 뛸 선수·다음 뛸 선수와 승패 입력, 목록 버튼으로 전체 명단·출전 현황·경기 기록을 봅니다. 개인전(부스)은 가나다순 명단에서 이름을 눌러 점수를 입력합니다.
  - **감독**(청팀·홍팀): 위쪽은 출전 순서(번호), 아래쪽은 아직 넣지 않은 팀원(가나다순, 왼쪽부터 빈틈없이)입니다. 아래 팀원을 누르면 번호가 붙어 순서 맨 뒤에 들어가고, 끌어다 놓으면 원하는 자리에 들어갑니다. 순서 안에서도 ⠿ 손잡이를 끌어 위치를 바꿉니다. 상대 팀 순서와 지금 경기도 실시간으로 봅니다. 이미 뛴 선수는 순서가 고정됩니다.
  - **안내판**(가로로 세운 태블릿): 단체전은 위쪽에 "청팀 ○○○ · 홍팀 ○○○ 준비해 주세요" 호출 띠, 가운데에 지금 경기를 크게 보여 줍니다. 결과가 들어오면 화면을 위(승리 팀)·아래(패배 팀)로 나눠 7초 동안 보여 준 뒤 준비할 선수를 부릅니다. '준비해 주세요'로 부를 선수는 마스터가 다음·다다음(기본)·세 번째 뒤 가운데에서 고르고, 다다음 이상이면 안내판에 사이의 다음 경기도 작게 보여 줍니다. 심판은 '📣 지금 선수 다시 부르기 / 다음 선수 부르기'로 언제든 부를 수 있습니다. 개인전 때는 전체 명단과 종목별 점수를 보여 주고, 이름을 누르면 그 사람 기록만 한 화면에 크게(저시력용), 한 번 더 누르면 목록으로 돌아갑니다.
  - 안내판 소리·효과: 띵동(호출), 호출 이름 읽기(음성 합성), 깜빡임(농인을 위해 1초 간격으로 테두리·글씨 반전)을 마스터가 켜고 끕니다. 태블릿은 처음 켤 때 화면을 한 번 눌러야 소리가 납니다.
  - 문자 안내방송(마스터): 적은 글을 안내판에 15초 동안 화면 가득 띄우고 읽어 준 뒤, 내릴 때까지 위쪽 띠로 계속 보여 줍니다. 앞에 딩동댕동 차임벨(켜고 끄기)을 넣을 수 있고, 자주 쓰는 문구를 저장해 둡니다.
  - 마스터의 '안내판' 메뉴는 위쪽 탭(화면·소리·안내방송·시상식·현황)으로 나뉩니다. '화면' 탭에서 안내판에 띄울 화면(자동·개인전 명단·종합 현황·종목 고정)과 준비 호출 순번을 고르고 미리 보기를 하며, '소리' 탭에서 소리 시험을 합니다.
- **무전기**(마스터·감독·심판): 머리줄 오른쪽(메뉴 버튼 왼쪽)의 작은 🎙 버튼을 누르면 가운데에 무전 창이 뜹니다. 창 위쪽 탭으로 🎙 무전 · 📢 방송(권한이 있을 때) · 💬 문자를 오갑니다. 큰 동그란 버튼을 누르고 있는 동안 말하면 다른 진행요원 기기에서 목소리가 나오고, 창을 닫아 둔 기기에는 위쪽에 '🔊 ○○○ 말하는 중'이 뜨며 🎙 버튼이 노랗게 깜빡입니다. 동시에 먼저 누른 한 사람만 말할 수 있습니다.
  - **로저 비프음**: 버튼을 누르면 '연결 중…'으로 바뀌고, 무전 잡기와 마이크 준비가 모두 끝난 순간에 무전 시작 효과음(로저 비프음, 0.16초)이 납니다. 목소리는 비프음이 끝나는 순간부터 보내므로 비프음을 듣고 바로 말하면 됩니다. 손을 뗀 뒤에도 0.2초 더 받아서 마지막 말이 잘리지 않게 합니다. 듣는 기기에서도 무전이 시작될 때 같은 비프음이 난 뒤 목소리가 나옵니다. 한 번에 60초까지이고, 무전 창에서 '다른 사람 무전 듣기'를 끌 수 있습니다.
- **일정·시간 안내**(마스터 '일정·알림' 메뉴): 일정(예: 12:40 점심시간 끝)과 알림 시점(30·15·10·5·3·1분 전), 받을 사람(모든 진행요원·감독·심판·개인전 담당·단체전 담당·마스터)을 정하면, 그때마다 해당 기기에 소리·진동과 함께 "○○까지 5분 남았습니다" 안내 창이 뜹니다. 안내판에도 띄우기를 켜면 안내판 위쪽에 남은 시간이 보이고 알림 때 읽어 줍니다. '바로 타이머'(지금부터 ○분)와 '지금 바로 알림 보내기'도 있습니다.
- **문자 무전·긴급 호출**: 오른쪽 💬 버튼에서 '선수 준비 완료' 같은 문구를 누르면 받을 사람 기기에 안내 창이 뜹니다. 🚨 긴급 호출은 모든 진행요원 화면에 빨간 경고 창을 띄우고 확인할 때까지 울립니다.
- **출석 체크**: 메뉴의 '출석 체크'에서 오지 않은 선수를 불참으로 표시하면 단체전 순서에서 자동으로 건너뛰고, 명단·안내판에도 표시됩니다.
- **시상식**: 마스터 '안내판' 메뉴에서 시상식 화면으로 바꾸고 '다음 발표'를 누르면 개인전 종목별 3등 → 2등 → 1등, 마지막에 종합 우승을 팡파르·이름 읽기와 함께 크게 보여 줍니다.
- **결과 보고서**: '명단·설정'에서 종합 결과·개인전 순위·단체전 대결 기록·불참자를 A4로 인쇄하거나 PDF로 저장합니다. **시험 기록 초기화**로 운동회 전에 시험해 본 기록을 한 번에 지웁니다(명단·담당자·역할·일정은 남음).
- **음성 안내방송**(마스터, 마스터가 권한을 준 감독·심판): 📢 버튼을 누르고 있는 동안 안내판(블루투스 스피커)으로만 방송합니다. 안내판에서는 딩동댕동 차임벨(켜고 끄기) 뒤에 목소리가 나오고, 위쪽에 "📢 안내방송 중" 띠가 깜빡입니다. 방송 중에는 선수 호출 소리를 방송이 끝난 뒤로 미룹니다. 스피커 가까이에서 말하면 '삐' 하울링이 생기니 몇 미터 떨어져서 말해 주세요.
- 음성은 0.15초씩 잘라 전화 음질(무전 8kHz, 방송 16kHz μ-law)로 줄여 Firebase Realtime Database로 중계합니다. 듣는 기기는 음성 줄을 처음부터 열어 두고, 0.7초 넘게 밀리면 밀린 조각을 버리고 따라잡습니다. 마이크는 말을 마친 뒤 20초 동안 켜 두어 이어서 말할 때 바로 시작됩니다. 무전 1시간에 듣는 기기 20대 기준 약 0.8GB로, 무료 한도(월 10GB) 안입니다. 말할 사람·들을 사람·방송 권한은 서버 규칙(`database.rules.json`)이 확인합니다.
- 화면 버튼만 숨기는 것이 아니라 서버 규칙(`firestore.rules`)이 기기마다 역할을 확인합니다. 심판은 맡은 종목의 기록만, 감독은 자기 팀 순서만 쓸 수 있습니다.
- **메뉴 안 탭**: 마스터의 안내판(화면·소리·안내방송·시상식·현황), 일정·알림(진행 일정·바로 타이머·바로 알림), 역할(접속 기기·담당자 명단·역할 안내), 명단·설정(명단·명단 넣기·팀·점수·보고서·초기화) 메뉴는 위쪽 탭으로 나뉘어 있어 안에 무엇이 있는지 바로 보입니다.
- **한 화면 구성**: 경기 화면은 스크롤 없이 한 화면에 들어갑니다. 머리줄의 종목 버튼(예: ⚽ 짐볼 차기 ▾)으로 종목·맡은 일을 바꿉니다. 명단·순위·기록은 📋 버튼의 창에서 봅니다.
  - 단체전: 위쪽에 지금 대결(청팀·홍팀 선수 나란히)과 승패 버튼, 아래쪽에 **대기 순서**(다음 대결부터 청·홍을 한 줄씩)와 **남은 대결 수**를 보여 줍니다. 준비 호출할 줄에는 '📣 준비'가 붙고, 모두 한 번씩 나온 뒤 다시 나오는 순서는 흐리게 보입니다. 선수 카드를 누르면 선수 고르기 창(순서대로·안 한 사람 먼저·가나다)이 열리고, 출전 명단 창도 청팀·홍팀을 나란히 보여 줍니다. 휴대폰을 가로로 들면 왼쪽에 지금 대결, 오른쪽에 대기 순서가 놓입니다.
  - 양궁·투호: 두 사대(칸)를 세로 화면에서는 위아래, 가로 화면에서는 왼쪽·오른쪽에 함께 띄워 두 명을 동시에 입력합니다. 빈 칸을 누르면 명단 창(안 한 사람 먼저·가나다·팀별)이 열립니다.
- 개인전: 양궁(과녁 5·배너 3·밖 0, 거리 2.5m/3m), 후리볼(네트 안 5·닿음 3·라인 안 2·파울 1·헛스윙 0), 투호(30·20·10·0점, 거리 구분 없음)를 1인 5회 입력합니다. 투호·양궁은 두 명을 동시에 입력합니다. 본경기·결승을 나누고, 1~3등 안의 동점을 표시합니다.
- 단체전: 짐볼 차기·2인3각·콩주머니·줄 잡고 달리기·줄다리기. 감독이 정한 순서대로 출전 횟수가 가장 적은 사람이 다음 선수로 나오고, 이긴 팀에 승점 1점이 쌓입니다. 빠진 사람이 있으면 심판이 '선수 바꾸기'로 이번 대결 선수를 직접 고르고, 다른 심판 기기와 안내판에도 바로 반영됩니다.
- 기록마다 입력자·시각이 남고, 고친 기록은 이전 값도 남습니다. 인터넷이 끊겨도 기기에 보관했다가 다시 연결되면 올립니다.
- 주소 뒤에 `?demo=1`을 붙이면 이 브라우저에만 저장하는 연습 모드로 열립니다(마스터 비밀번호 `0000`, 탭마다 다른 기기처럼 동작).

### Firebase 설정 (한 번만)

`handscil-sports` 프로젝트(console.firebase.google.com)에서 합니다.

1. **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명**을 켜고 저장합니다. 기기마다 고유 번호를 받아 역할을 확인하는 데 씁니다.
2. **Firestore Database → 데이터**에서 `undonghoe5` 모음에 문서 ID `secret`인 문서를 만들고, 필드 `masterPw`(문자열)에 마스터 비밀번호를 넣습니다. 이 문서는 규칙상 아무도 읽을 수 없습니다.
3. **Firestore Database → 규칙** 탭에 `sports-day/firestore.rules` 내용을 그대로 붙여 넣고 게시합니다. 쓰기는 2026년 11월 7일까지만 허용됩니다.
4. **Realtime Database**를 싱가포르(asia-southeast1)에 만들고(주소 `handscil-sports-default-rtdb.asia-southeast1.firebasedatabase.app`), **데이터** 탭에서 `undonghoe5` → `secret` → `masterPw`에 2번과 같은 마스터 비밀번호를 넣습니다.
5. **Realtime Database → 규칙** 탭에 `sports-day/database.rules.json` 내용을 그대로 붙여 넣고 게시합니다. 이 파일에는 손잡다 야구의 온라인 대전 규칙(`baseball` 부분)도 함께 들어 있습니다. 운동회 규칙(`undonghoe5` 부분)은 바뀌지 않았습니다.
6. 이 설정 전에 마스터로 들어와 있던 기기는 무전기 옆 '🔒 무전기 권한 확인'을 눌러 비밀번호를 한 번 더 넣습니다. 감독·심판 기기의 무전 권한은 마스터 기기가 켜져 있을 때 자동으로 맞춰집니다.

## 손잡다 야구 (`baseball/`)

시청각장애인이 화면을 보지 않고도 할 수 있는 "듣고 고르는 확률 야구"입니다. 보이스오버·톡백, 한소네 같은 점자 단말기, 리보 같은 숫자판 블루투스 키보드로 할 수 있습니다. 앞으로의 계획은 `baseball/PLAN.md`에 있습니다(2단계 온라인 대전·채팅·음성 대화, 3단계 감독 모드).

- **고르는 방법**: 모든 화면이 "질문 하나 + 번호 붙은 선택지"입니다. 단추를 누르거나, 숫자 키를 누르거나, 명령 칸에 숫자·낱말을 적어 고릅니다. 공통 키: 0 지금 상황, 점(.) 뒤로, 더하기 점수판, 빼기 타자·투수 정보, 나누기 최근 기록, 곱하기 키 안내.
- **읽어 주기**: 단추로 고르면 결과 글로 초점이 옮겨 가 화면 낭독기가 바로 읽고, 키나 명령 칸으로 고르면 초점은 그대로 두고 알림으로 읽어 줍니다. 결과는 아래 중계 기록에 한 줄씩 남습니다(점자 단말기로 한 줄씩 읽기). 화면 낭독기를 쓰지 않는 사람은 설정에서 기기 음성으로 읽게 바꿉니다.
- **온라인 대전**: 한 사람이 방을 만들고 방 코드 네 자리(또는 카카오톡으로 보내는 초대 링크)를 알려 주면, 상대는 숫자 네 자리를 누르거나 링크를 열어 이름만 적고 들어옵니다. 두 사람이 각자 자기 팀만 고르고, 방장 기기가 경기를 계산합니다.
  - **공정하게**: 손님이 고른 공·타격은 방장 기기에만 가고(서버 규칙으로 손님 자신과 방 밖의 사람은 못 읽음), 방장이 고른 것은 서버에 올리지 않습니다. 방장 기기는 손님이 보낸 선택이 손님 팀 차례인지, 값이 맞는지 확인한 뒤에만 씁니다. 방 밖의 사람은 경기 상태를 읽거나 쓸 수 없습니다.
  - **채팅**: 명령 칸에 글을 적고 입력하면 보냅니다(선택지 이름과 똑같은 글은 그 선택지를 고름). 빠른 문구 6가지. 받은 채팅은 바로 읽어 주고(설정에서 끄기), 화면 아래 채팅 목록에 남습니다.
  - **음성 대화**: WebRTC로 두 기기가 직접 연결해 목소리가 서버를 거치지 않습니다(서버에는 연결 신호만 잠깐 오감). 기기마다 **통화**(계속 켜 두고 마이크 끄기·켜기)와 **무전기**(머리줄의 말하기 단추를 누르는 동안 말하기, 화면 낭독기는 두 번 탭으로 켜고 끄기, 시작할 때 삑 소리, 한 번에 60초까지) 가운데 고릅니다. 일부 휴대폰 데이터망에서는 직접 연결이 안 될 수 있어, 그때는 와이파이로 바꾸거나 채팅을 쓰라고 안내합니다(`baseball/js/net.js`의 `TURN_SERVERS`에 중계 서버를 넣으면 해결됨).
  - 연결이 끊기면 상대에게 알리고, 같은 기기에서 다시 열어 "방 다시 들어가기"를 누르면 이어 합니다. 경기가 끝나면 방장이 "한 판 더"로 바로 새 경기를 시작합니다.
  - 서버는 운동회 앱과 같은 Firebase 프로젝트(`handscil-sports`)의 Realtime Database `baseball/rooms/{방 코드}`를 씁니다. **처음 한 번** Firebase 콘솔의 Realtime Database → 규칙 탭에 `sports-day/database.rules.json` 내용을 붙여 넣고 게시해야 온라인 대전이 됩니다(운동회 규칙은 그대로이고 `baseball` 부분이 더해진 파일입니다).
- **혼자 하기**(컴퓨터와, 쉬움·보통·어려움), **둘이 하기**(한 기기를 번갈아: 수비가 먼저 고르고 "기기 넘기기" 화면 뒤에 공격이 고름), **컴퓨터끼리 관전**(다음 공·타석·이닝·경기 끝까지, 자동 재생). 1·3·5·7·9이닝, 동점이면 연장 3이닝까지.
- **간단 모드**: 타석마다 한 번 고르고(강하게·보통·맞히기·번트·도루 / 정면 승부·유인구 승부·고의 볼넷) 1~100 주사위로 결과를 정합니다. 선택지마다 안타·홈런·삼진 확률이 나옵니다.
- **정밀 모드**: 공마다 구종 → 코스(스트라이크 존 9칸, 숫자판 배열 전화기식·컴퓨터식 선택) → 붙이는 정도(존 안쪽·구석·빼기) → 세기(전력·보통·힘 빼고, 예상 구속 표시)를 고르고, 타자는 치기·강하게·맞히기·지켜보기·번트·도루·노림수를 고릅니다. 수비 위치(내야·외야 전진·보통·후진), 고의 볼넷, 투수 교체, 맡기기(이번 공·타석·이닝)도 있습니다.
- **감독 모드**: 선수들이 공 하나하나를 알아서 던지고 치며, 감독은 경기 전 준비와 작전만 맡습니다.
  - 경기 전: 추천 타순, 두 타자 순서 바꾸기, 벤치 선수 넣기, 선발 투수 고르기(내 팀 능력치는 숫자로) 뒤 "준비 완료".
  - 작전은 중요한 순간(득점권 주자, 무사 1루, 경기 후반 접전, 우리 투수가 지쳤거나 점수를 많이 줬을 때)에만 묻고, 그 사이 타석은 선수들이 진행해서 "타자 이름: 결과"로 모아 읽어 줍니다. 더 보기에서 매 타석 묻기, 공 하나하나 중계로 바꿀 수 있습니다.
  - 공격: 타자에게 맡기기, 적극적으로 쳐라, 신중하게 골라라, 번트(희생·스퀴즈·기습), 도루, 히트 앤드 런(1루 주자가 먼저 뛰고 타자는 꼭 맞힘: 병살 없음, 한 베이스 더, 대신 헛스윙·직선타 위험), 대타, 대주자. 수비: 투수에게 맡기기, 정면 승부, 어렵게 승부, 고의 볼넷, 투수 교체, 수비 위치.
  - 팀마다 벤치 선수 4명(장타 대타·교타 대타·대주자·수비 요원). 바뀌어 나간 선수는 다시 나오지 못하고 기록은 남습니다. 컴퓨터 감독도 경기 후반 접전에서 대타·대주자·투수 교체를 씁니다.
  - 혼자 하기, 둘이 하기, 관전, 온라인 대전(감독끼리 대결) 모두 됩니다. 온라인에서 손님의 타순·교체 요청은 방장 기기가 확인한 뒤 적용합니다.
- **결과에 영향을 주는 것**: 경기마다 새로 정하는 선수 능력치(타자 컨택·파워·선구안·스피드·수비·성향, 투수 구속·제구·구위·체력·구종 완성도), 컨디션, 팀 스타일(장타형·교타형·기동력형·투수력형·수비형·균형형), 바람, 수비 위치, 볼카운트, 타이밍, 투구 수에 따른 피로. 상대 팀 능력치는 등급으로만 보입니다. 설정의 "판정 과정 보기"를 켜면 주사위와 확률이 기록에 함께 나옵니다.
