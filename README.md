# Sungmo

## 성경 부루마블 (`bible-marble/`)

주사위를 굴려 우르에서 예루살렘까지 성경의 땅을 여행하는 보드게임입니다. 파일 하나(`bible-marble/index.html`)로 되어 있어 브라우저로 바로 열 수 있습니다.

- 2~4명, 자리마다 사람 또는 컴퓨터를 고를 수 있습니다.
- 말씀 퀴즈 난이도: 쉬움 / 보통 / 어려움 / 섞어서 (약 140문항, 모든 문항에 성경 구절 표시)
- 보드 32칸: 시대별 8개 그룹의 땅 20곳, 명소 2곳(홍해, 요단강), 말씀 카드, 말씀 퀴즈, 광야, 오병이어 헌금함, 엘리야의 불수레, 십일조
- 땅 위에 장막 → 집 → 성을 지을 수 있고, 남의 땅에서는 말씀 찬스 퀴즈를 맞히면 통행료가 반값이 됩니다.
- 진행 중인 게임은 브라우저에 자동 저장되어 "이어하기"로 다시 시작할 수 있습니다.

## 난장이의 피아노 교실 (`piano/`)

피아노를 처음 치는 사람이 코드(화음)를 차근차근 익히는 연습 앱입니다. 팬플룻 교실과 같은 모양의 PWA로, `piano/` 폴더를 그대로 웹에 올리면 홈 화면에 설치할 수 있습니다.

- 다섯 단계: 첫걸음(건반·손가락·반음) → 기본 코드(C, Cm) → 7화음 → 색깔 코드(sus·dim·aug) → 활용(자리바꿈, 코드 진행, 노래 반주)
- 코드 이름은 정석 표기로 보여 줍니다. 예: Cm = 도 · 미♭ · 솔 (미♭이 레♯과 같은 건반이라는 안내를 함께 표시)
- 입력 방법 세 가지를 함께 쓸 수 있습니다.
  - 화면 건반: ‘콕콕’(하나씩 켜기) / ‘꾹’(누르는 동안) 방식
  - 디지털피아노 MIDI 연결 (안드로이드 크롬, PC 크롬·엣지)
  - 마이크: 진짜 피아노 소리를 듣고 여러 음을 함께 판정 (https 주소나 설치한 앱에서 동작)
- 연습: 코드 원리 배우기, 건반 찾기, 반음·온음 세기, 코드 짚기, 코드 이름 맞히기, 귀로 맞히기, 코드 진행(기다려 줘요 / 박자대로, 가까운 자리바꿈 추천), 노래 반주(작은 별, 환희의 송가, 생일 축하 노래, 징글벨, 어메이징 그레이스)
- 그 밖에: 누른 건반의 코드 이름 알아보기, 코드 사전, 메트로놈, 연습 기록과 코드별 실력, 기록 파일 보관
