# 기안 도우미 설계안 (초안)

사업 기안(회계 기안 제외)을 사업계획 → 회차 문서 → 결과보고 → 실적까지 한 줄로 이어서 관리하고,
반복되는 기안은 앞 문서를 바탕으로 자동으로 채우는 PC용 웹 앱의 설계안입니다.
기존 앱 `doc-check/`(기안 점검판)를 점검 화면으로 포함합니다.

> 개인정보 원칙: 이 문서와 저장소에는 참여자·직원 이름, 실제 문서 번호와 제목을 넣지 않습니다.
> 실제 기안 내용은 사용자 PC(브라우저 저장소 또는 사용자가 고른 폴더의 데이터 파일)에만 둡니다.

---

## 1. 현재 기안 구조 파악

근거: `doc-check/`에 들어 있는 사업 사전·서류 종류 규칙, 2026년 문서대장 분류 통계(채워진 줄 638건).

### 1-1. 사업 체계 (단위사업 → 세부사업)

| 단위사업 | 세부사업 | 회차를 나누는 방식 |
|---|---|---|
| 권익옹호 | 배리어프리존형성 | 반기(상반기·하반기) |
| | 서비스모니터링, 정책제안 | 단발 |
| | 장애공감캠페인 | N차 |
| 동료상담 | 개별동료상담 | 사람별 |
| | 자조모임 | 분기별 운영계획·결과보고, 회기별 진행비 |
| | 대상자발굴 | 단발 |
| 개인별자립지원 | 개별자립지원 | 사람별(사전회의 → 계획 → 연계 → 중간회의 …) |
| | 자립생활프로그램 | 교육(강좌)별 계획·결과보고, 강사비는 월별 |
| 장애인지역사회자립지원 | IL연수, 자립생활단기체험 | 단발(변경계획 잦음) |
| 문화여가활동 | 지역사회체험활동 | N차 |
| | 체육대회 | 단발(수정 운영계획 있음) |
| 활동가역량강화 | 직원교육 | N차 |
| | 사업평가회 | 단발 |
| 구지원사업(감각 채움 공방) | 꽃꽂이·라탄공예·양말목공예·천연제품 교실 | 교실별 |
| 복지증진(공모) | 요리클래스 | 반별(기초반·심화반) |
| 2회 복지증진 | 레크타임, 윷놀이한마당, 퀴즈대회 | 행사별 |
| 생활체육교실 | PT 교실 | 기간 운영 |

재원(돈이 나오는 곳)이 사업마다 다릅니다: 자립지원사업 보조금, 구 지원사업, 복지증진 공모, 생활체육(체육회), 한국장애인재단.
같은 진행비 안에서도 보조금·자부담을 나누어 쓰는 경우(예: 재료비-보조금 / 재료비-자부담)가 있으므로 예산에는 **재원 구분**도 필요합니다.

### 1-2. 문서 흐름 (한 해)

```
[연간]  사업계획(1월)
          │  내역변경 승인요청(보조금) ──► 사업 변경계획 ──► (새 기준)
          ├─ 상반기 실적보고 및 하반기 계획(7월)
          ├─ 변경계획(하반기, 여러 번 가능)
          └─ 연간 실적

[회차]  운영계획 (회차마다; 바뀌면 '수정 운영계획')
          ├─ 참여자 모집 홍보 (내부결재 + 대외 공문 + 안내문)
          ├─ 홍보비            (현수막 등)
          ├─ 대관료 · 보험(배상책임공제)   ← 돈이 먼저 나가고 붙임 서류가 따로 있어 보통 따로 기안
          ├─ 진행비            (식비·다과비·재료비·체험비·물품구입비를 보통 묶어서)
          ├─ 강사비 · 통역비    (진행비 뒤, 지급 서류 따로)
          └─ 결과보고          (반드시 있음: 출석, 결산 = 그 회차 지출 기안 합계, 만족도, 일지·출석부 붙임)
```

기안 점검판이 이미 확인하는 순서 규칙: 계획이 지출보다 앞 번호, 결과보고가 맨 뒤, 모집은 지출보다 앞(홍보비 제외), 강사비·통역비는 진행비 뒤,
개별자립지원은 사전회의 → 계획.

### 1-3. 기안 제목 패턴

- 파일 이름: `손잡다YY-번호 MMDD 제목.hwp(x)`, 미리 작성할 때는 번호 `0000`.
- 연간: `YYYY년 단위사업-세부사업 사업 계획`, `… 사업 변경 계획`, `… 상반기 실적보고 및 하반기 계획`
- 회차: `세부사업 N차 계획`, `세부사업 N차 참여자 모집 홍보`, `세부사업 N차 진행비`, `… 결과보고`
- 사람별: `개별자립지원(이름) 사전회의 진행 보고`, `… 계획`, `… 자조모임 연계`
- 교육별: `자립생활프로그램 ○○ 교육(강사) 계획`, `자립생활프로그램 N월 강사비`
→ 제목은 앞 문서 제목에서 회차·날짜만 바꾸는 규칙으로 자동 생성할 수 있습니다.

### 1-4. 계정과목

- 4단계 경로로 적습니다. 예: `사업비 / 사업진행비 / 문화여가활동 / 체험활동`, `사무비 / 운영비 / 운영비 / 수용비 및 수수료`
- 같은 사업이라도 품목마다 계정과목이 다를 수 있습니다(예: 홍보비는 사무비 쪽).
- 문구를 바꾸면 안 됩니다(예: 세목을 '지역사회체험활동'이 아니라 '체험활동'으로 써야 함).
  → 앱에서는 계정과목을 **목록에서 고르기만** 하고 직접 입력하지 못하게 잠급니다.

### 1-5. 이미 쌓인 작성 규칙(가이드 초안으로 쓸 것)

- 변경계획의 변경사유에는 예산을 어디로 옮기는지 쓰지 않고 바뀌는 내용만 씁니다.
- 예산 산출근거의 횟수는 여유 있게 잡은 값이므로, 산출목표(실인원·연인원·횟수)를 거기에 맞추지 않습니다.
- 참가 인원 명단에는 실제로 오지 않는 사람을 넣지 않습니다(예산 인원과 실제 이용 인원은 다를 수 있음).
- 앞 기안을 복사해 쓰다가 다른 사업의 사업명·세부사업명이 남는 오기가 실제로 있었습니다 → 앱이 잡아야 할 대표 실수.
- 결과보고 결산은 그 회차 진행비 + 통역비 등 지출 기안 합계와 같아야 합니다.

## 2. 앱 구조

### 2-1. 데이터 모델

```
연도
 └ 단위사업 → 세부사업
     ├ 계획 버전들: v1 사업계획 → v2 변경계획 → …   (각 버전 = 목적·목표·전략·회차 일정·수행인력·예산)
     ├ 예산 줄: 계정과목(잠금) · 품목 · 재원 · 단가 × 인원 × 횟수 = 금액
     ├ 회차들: 1차, 2차 … (또는 사람·반·교실·분기)
     │    └ 문서들: 운영계획, 모집, 홍보비, 대관료, 보험, 진행비, 강사비, 통역비, 결과보고
     │         · 지출 문서는 '예산 줄'에 금액을 연결 → 잔액 자동 차감
     │         · 결과보고는 출석 명단·결산(지출 합계)·만족도를 가짐
     └ 실적: 결과보고에서 자동 집계(실인원 = 중복 없는 사람 수, 연인원, 횟수) vs 목표
```

- **기준선 규칙**: 회차 문서는 항상 "지금 유효한 계획 버전"에서 값을 가져옵니다. 변경계획을 저장하면 그 뒤 문서는 새 버전을 따릅니다.
- **변경계획 만들기**: "무엇이 바뀌나"(예산 줄 금액, 회차, 목표 등)만 입력하면 당초/변경/증감 비교표와 변경사유 초안을 만들어 줍니다.
  보조금 내역변경(다른 세부사업으로 예산 이동)이면 줄어드는 사업과 늘어나는 사업 양쪽에 변경계획 초안이 같이 생깁니다.

### 2-2. "바뀐 것인지, 실수인지" 판별

새 문서를 만들 때 **같은 종류의 최근 문서**를 틀로 쓰고, 칸마다 아래처럼 비교합니다.

| 칸 종류 | 예 | 처리 |
|---|---|---|
| 회차마다 바뀌는 칸 | 일시, 장소, 회차, 프로그램 내용, 모집 기간 | 새로 입력하도록 비워 두거나 계획에서 가져옴 |
| 계획에서 오는 칸 | 사업명, 목적, 계정과목, 단가, 수행인력 | 현재 계획 버전 값으로 채움 |
| 고정이어야 하는 칸 | 기관명, 사업총괄, 결재선, 붙임 목록 틀 | 최근 문서와 그 이전 문서가 다르면 표시 |

최근 문서와 그 이전 문서의 값이 다를 때:
- 사이에 변경계획이 있고 그 변경으로 설명되면 → **변경 반영**(초록)
- 설명할 근거가 없으면 → **확인 필요**(노랑): "이번에 바뀐 것인지, 앞 문서를 고치다 남은 실수인지" 두 값을 나란히 보여 주고 사용자가 고름
- 고른 결과는 기억해서 다음부터 같은 질문을 하지 않음

### 2-3. 화면

1. **사업 현황판**: 세부사업 × 회차 표(기안 점검판의 표를 확장). 빈 칸에 `만들기` 버튼 → 앞 문서·계획으로 채운 작성 화면으로 이동.
2. **계획**: 버전 목록, 버전 간 차이 보기, 변경계획 만들기.
3. **예산**: 계정과목별·품목별 계획액 / 집행액 / 잔액, 재원별 합계, 회차별 사용 내역. 결과보고 결산과 지출 합계가 다르면 경고.
4. **작성**: 문서 종류별 입력 화면(채울 칸만 강조), 오른쪽에 작은 가이드(꼭 들어갈 것·주의할 것·붙임 서류).
5. **실적**: 목표 대비 실인원·연인원·횟수, 상반기 실적보고·연간 실적 초안, 평가지표 항목별 정리.
6. **점검**: 기존 기안 점검판(번호 누락·스캔 누락·순서).
7. **안내(튜토리얼)**: 문서 종류별 단계 안내 모드.

### 2-4. 문서 만들기와 마무리

- 1단계: 앱이 채운 내용을 **기안 묶음 파일(JSON + 읽기 쉬운 요약)** 로 내보냄 → Claude(PC 연결 세션)가 한글(HWPX) 양식에 넣고 일지 등 서술 부분을 마무리해 `내부기안 미리 작성` 폴더에 저장.
- 2단계: 표 줄 수가 고정된 단순 문서(모집 홍보, 홍보비, 진행비 등)는 앱이 HWPX 양식에 직접 채워서 저장.
- 강사비·통역비 지급 서류, 다과비 계산기(`snack-calc/`), 명찰 만들기(`name-badge/`)를 같은 회차 데이터로 연결.

### 2-5. 저장

- 기본: 브라우저(IndexedDB) + 내보내기·가져오기.
- 권장: 사용자가 고른 시놀로지 폴더에 데이터 파일 하나(`기안도우미-YYYY.json`)만 쓰기 → 다른 PC에서도 같은 데이터.
  (기안·스캔 폴더는 기안 점검판처럼 **이름만 읽고 쓰지 않음**.)
- 과거 문서 내용 읽기(학습)는 HWPX만 브라우저에서 가능하고, HWP는 Claude가 PC에서 읽어 데이터 파일로 만들어 넣는 방식.

## 3. 단계별 계획

| 단계 | 내용 | 확인 기준 |
|---|---|---|
| 0 | 구조 확정: 계정과목표·사업별 예산표 원본, 문서 종류별 양식 확보 | 사용자 확인 |
| 1 | 시범 사업 하나(지역사회체험활동 권장: 회차·변경계획·진행비·통역비가 모두 있음)로 계획 버전 + 예산 잔액 + 회차 표 | 올해 실제 수치와 잔액이 맞음 |
| 2 | 회차 문서 만들기(앞 문서 비교, 확인 필요 표시) + 기안 묶음 내보내기 → Claude 마무리 | 다음 회차 기안을 실제로 이 방식으로 작성 |
| 3 | 기안 점검판 통합(빈 칸 → 만들기), 다른 세부사업으로 확대 | 모든 세부사업 표가 채워짐 |
| 4 | 결과보고 → 실적 자동 집계, 상반기 실적보고·연간 실적 초안, 평가지표 연결 | 목표 대비 실적 표가 대장과 맞음 |
| 5 | 튜토리얼 모드, 다음 해 사업계획 초안(올해 마지막 버전 기준) | 신규 직원이 안내만 보고 작성 가능 |

## 4. 추가로 넣으면 좋은 기능

- **할 일 목록**: 회차 날짜 기준으로 "계획 결재 → 모집 → 지출 → 결과보고" 기한 표시(D-day).
- **붙임 서류 체크리스트**: 대관 신청서·안전수칙 확인서, 보험 증권, 강사 신분증·통장 사본, 통역 확인서, 출석부, 만족도 조사지.
- **번호 붙이기 도우미**: `0000` 문서가 대장 번호를 받으면 파일 이름 바꿀 목록을 알려 줌.
- **결산 대조**: 결과보고 결산 = 지출 기안 합계, 출석 인원 ≤ 예산 인원, 단가 × 인원 계산 확인.
- **내역변경 영향 미리 보기**: 예산을 옮기면 어느 사업 어느 회차 잔액이 얼마가 되는지.
- **문구 사전**: 목적·필요성·추진전략 문장을 버전별로 보관, 바뀐 곳만 강조.
- **참여자 명부(기기 안에만)**: 출석으로 실인원·연인원 자동 계산, 개인정보는 저장소·서버로 보내지 않음.
