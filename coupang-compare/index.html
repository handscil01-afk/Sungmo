쿠팡 비교견적 도우미

쿠팡 장바구니에 담은 물품을 11번가와 G마켓에서 차례로 찾아 장바구니에 담고, 세 곳의 금액을 비교표로 정리합니다. PC 크롬의 템퍼몽키에서 동작합니다.

설치하기 (처음 한 번)

  1. 크롬에 템퍼몽키(Tampermonkey) 확장 프로그램을 설치합니다.
  2. 크롬 주소창에 chrome://extensions를 입력하고, 템퍼몽키의 세부정보에서 사용자 스크립트 허용을 켭니다.
  3. 아래 버튼을 누르고, 템퍼몽키 화면에서 설치를 누릅니다.
스크립트 설치하기

새 버전을 올리면 템퍼몽키가 자동으로 업데이트합니다.

사용 순서

  1. 쿠팡 장바구니에 살 물품을 담고 장바구니 화면을 엽니다.
  2. 오른쪽 아래 비교견적 시작을 누르고, 견적에 넣을 물품과 검색어를 확인합니다.
  3. 11번가 검색 화면 오른쪽 패널의 후보 중 하나를 고릅니다.
  4. 상품 화면에서 옵션을 직접 고르고 수량 맞추기 → 장바구니 담고 기록을 누른 뒤 다음 상품으로 넘어갑니다.
  5. 11번가가 끝나면 G마켓에서 같은 순서로 진행합니다.
  6. 마지막 요약에서 표를 복사하고, 세 곳의 장바구니 화면을 캡처해 견적서로 씁니다.

알아 둘 점

  1. 이 스크립트는 장바구니에 담기까지만 합니다. 구매하기·결제·선물하기 버튼은 누르지 않습니다.
  2. 상품과 옵션(색상·사이즈)은 직접 고릅니다. 옵션이 여러 개면 수량도 직접 나눠 입력합니다.
  3. G마켓에서 '사람인지 확인' 화면이 나오면 직접 눌러 통과한 뒤 계속하면 됩니다.
  4. 쇼핑몰 화면 구조가 바뀌면 일부 기능이 멈출 수 있습니다. 그때는 수정한 버전을 다시 올립니다.
