쿠팡 비교견적 도우미

쿠팡 장바구니에 담은 물품을 11번가와 G마켓에서 차례로 찾아 장바구니에 담고, 세 곳의 금액을 비교표로 정리합니다. PC 크롬의 템퍼몽키에서 동작합니다.

설치하기 (처음 한 번)

  1. 크롬에 템퍼몽키(Tampermonkey) 확장 프로그램을 설치합니다.
  2. 크롬 주소창에 chrome://extensions를 입력하고, 템퍼몽키의 세부정보에서 사용자 스크립트 허용을 켭니다.
  3. 아래 버튼을 누르고, 템퍼몽키 화면에서 설치를 누릅니다.
스크립트 설치하기

새 버전을 올리면 템퍼몽키가 자동으로 업데이트합니다.

사용 순서

  1. 쿠팡 장바구니에 살 물품을 담고 장바구니 화면을 엽니다.
  2. 오른쪽 아래 비교견적 시작을 누르고, 물품마다 품명·묶음 개수(예: 24개입, 10쌍)·검색어를 확인합니다. 개당 가격이 자동으로 계산됩니다.
  3. 자동으로 전부 담기를 누르면 11번가와 G마켓에서 상품명이 가장 비슷하고 쿠팡보다 조금 비싼 상품을 골라 옵션·수량을 맞춰 장바구니에 차례로 담습니다. 중간에 멈추려면 패널의 자동 멈춤을 누릅니다.
  4. 하나씩 직접 고르려면 11번가부터 시작을 누르고, 패널의 후보 중 하나를 고른 뒤 장바구니 담고 다음을 누릅니다.
  5. 끝나면 요약이 열립니다. 잘못 담긴 품목은 표의 다시 버튼으로 고르고, 단가·금액 표를 복사합니다.
  6. 요약의 장바구니 열고 캡처 버튼(또는 장바구니 화면의 견적서 캡처)으로 장바구니를 캡처합니다. 자동으로 잡은 영역이 맞지 않으면 다른 영역 고르기에서 '장바구니' 제목부터 맨 아래 물건과 총 합계까지 끌어서 직접 지정합니다.
  7. 쿠팡 장바구니에서 수량을 바꿨다면, 쿠팡 장바구니 화면의 수량 변경 반영을 누릅니다. 바뀐 수량·금액이 기록에 반영되고, 요약에 11번가·G마켓의 맞춰야 할 수량이 표시됩니다.
  8. 11번가·G마켓 장바구니가 비었거나(로그인 전에 담아서 사라진 경우 등) 수량을 새로 맞추려면, 요약의 11번가·G마켓 다시 담기를 누릅니다. 기록해 둔 상품 주소와 옵션으로 새 수량에 맞춰 차례로 다시 담습니다. 옵션이나 수량이 자동으로 맞지 않으면 그 상품 화면에서 멈추니, 직접 고른 뒤 장바구니 담고 다음을 누르면 이어집니다. 판매가 중단됐거나 페이지가 열리지 않거나 담을 수 없는 상품은 같은 검색어로 쿠팡보다 비싼 비슷한 상품을 찾아 대신 담습니다. 이미 담긴 상품이 있으면 중복되므로 먼저 지우세요.
  9. 요약의 서류 만들기를 누르면 기안, 산출기초조사서(품명은 쿠팡 기준), 견적서(캡처 그림), 물품검수조서가 한 파일(.hwpx)로 만들어져 다운로드 폴더에 저장됩니다. 일시·장소·지출일 같은 칸은 서류 만들기 창에서 확인하고 고칩니다.

알아 둘 점

  1. 이 스크립트는 장바구니에 담기까지만 합니다. 구매하기·결제·선물하기 버튼은 누르지 않습니다.
  2. 옵션 자동 선택과 묶음 개수는 상품명·옵션 글자로 추측한 것이라 틀릴 수 있습니다. 패널의 옵션·묶음 개수·쿠팡 대비 %를 꼭 확인하세요. 상품명과 옵션의 개수가 다르면 패널에 알림이 뜹니다.
  3. 쿠팡보다 싼 후보도 보려면 패널의 쿠팡보다 비싼 것만 보기 체크를 끄세요.
  4. G마켓에서 '사람인지 확인' 화면이 나오면 직접 눌러 통과하세요. 자동 담기 중이면 통과한 뒤 저절로 이어집니다.
  5. 처음 캡처할 때 템퍼몽키가 '다른 사이트 접근 허용'을 물으면 항상 허용을 누르세요. 상품 사진을 캡처에 넣기 위해 필요합니다.
  6. 캡처는 화면을 그림으로 다시 그리는 방식이라 일부 아이콘·글꼴이 실제 화면과 조금 다를 수 있습니다. 캡처 영역이 맞지 않으면 다른 영역 고르기로 직접 고르세요.
  7. 서류 만들기로 받은 hwpx는 한글에서 열어 날짜·금액·품명과 결재란을 꼭 확인한 뒤 쓰세요. 견적서 그림은 직접 캡처한 장바구니가 그대로 들어갑니다.
  8. 쇼핑몰 화면 구조가 바뀌면 일부 기능이 멈출 수 있습니다. 그때는 수정한 버전을 다시 올립니다.
