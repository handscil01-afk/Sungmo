# DICEBOUND · 운명의 주사위

주사위 5개를 굴리고, 마음에 들지 않는 주사위만 골라 다시 굴려 족보를 완성하는 다크 판타지 로그라이크입니다. 분기형 맵을 따라 10층을 지나면 최종 보스(4종 중 하나)가 기다립니다.

- 주소: https://handscil01-afk.github.io/Sungmo/dicebound/
- 빌드 과정이 없습니다. 브라우저에서 `index.html`을 열면 바로 실행됩니다.

## 실행

```bash
# 저장소 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/dicebound/ 접속
```

`file://`로 직접 열어도 게임은 동작하지만, 서비스 워커(오프라인 실행)와 홈 화면 설치는 `http(s)://` 주소에서만 동작합니다.

## GitHub Pages 배포

1. 변경 사항을 `main` 브랜치에 병합합니다.
2. 저장소 Settings → Pages에서 Source가 `main` 브랜치 `/ (root)`인지 확인합니다. (이미 다른 앱이 이 설정으로 배포되고 있습니다.)
3. 몇 분 뒤 위 주소에서 확인합니다.
4. 파일을 추가하거나 바꾼 경우 서비스 워커 캐시를 새로 만듭니다: `python3 dicebound/tools/make_sw.py v2` (버전 문자열을 올립니다).

## 전투 규칙

- 내 차례가 시작되면 주사위 5개가 자동으로 굴러갑니다.
- 다시 굴릴 주사위를 눌러 고른 뒤 `재굴림`을 누릅니다. 고르지 않은 주사위는 그대로 남습니다. 재굴림은 턴마다 2번입니다(시간의 홀 +1, 재굴림 두루마리 +2).
- `공격`을 누르면 가장 강한 족보 하나의 효과가 적용되고, 적이 살아 있으면 예고한 행동을 합니다.

| 족보 | 효과 |
| --- | --- |
| 파이브 오브 어 카인드 | 공격 (눈 합×2+10), 방어 10, 회복 10 |
| 포카드 | 공격 (네 눈 합×1.5+6), 적에게 빙결 2 |
| 풀하우스 | 공격 (다섯 눈 합+4), 회복 6 |
| 스트레이트 (1~5, 2~6) | 공격 16 (2~6은 18), 방어 8 |
| 트리플 | 공격 (세 눈 합+8), 적에게 출혈 2 |
| 투 페어 | 공격 (네 눈 합+2), 방어 5 |
| 원 페어 | 공격 (두 눈 합+4) |
| 하이 카드 | 공격 (가장 높은 눈+2), 방어 3 |

상태 효과는 플레이어와 적에게 같은 규칙으로 적용됩니다.

| 상태 | 규칙 |
| --- | --- |
| 방어 | 받는 피해를 먼저 막습니다. 자기 차례가 다시 오면 사라집니다. |
| 출혈 | 자기 차례가 시작될 때 중첩만큼 피해(방어 무시), 중첩 -1 |
| 화상 | 자기 차례가 시작될 때 피해 3(방어 무시), 남은 턴 -1 |
| 빙결 | 공격 피해 ×0.7, 공격할 때마다 중첩 -1 |
| 힘 | 공격 피해 +중첩 (전투 동안 유지) |

공격 효과 계산 순서(`js/rules.js`의 `computeAttack`): 족보 기본 효과 → 특수 주사위 → 유물 고정 보너스 → 힘 → 왕의 왕관(×1.25) → 빙결(×0.7) → 상태 부여 보너스. 화면의 예상 피해와 실제 공격은 같은 함수를 사용하므로 서로 다르게 계산되지 않습니다.

중복 적용 방지: 전투 행동(`attack`)은 상태를 한 번에 끝까지 계산하고 연출 목록만 남깁니다. 화면은 그 목록을 재생할 뿐 상태를 바꾸지 않습니다. 보상·구매·이벤트 선택은 각각 `받음/판매 완료/완료` 표시를 확인한 뒤에만 적용되고, 특수 주사위 구매는 교체할 칸을 고른 순간에 한 번만 결제됩니다.

## 파일 구조

```
dicebound/
  index.html            화면 틀과 스크립트 연결
  css/style.css         전체 스타일 (휴대폰 세로 기준, 가로·태블릿·PC 대응)
  js/util.js            네임스페이스, 시드 난수, localStorage 래퍼
  js/data.js            족보·주사위·유물·소모품·적·NPC·업적 정의와 이미지 경로
  js/rules.js           순수 함수: 족보 판정, 공격 계산, 적 피해, 맵 생성·검증
  js/game.js            여정 상태와 모든 행동(맵 이동, 전투, 보상, 상점, 휴식, 이벤트, 저장, 도감·업적)
  js/ui.js              화면 그리기, 연출 재생, 모달, 정보창
  js/pwa.js             홈 화면 설치, 전체화면, 화면 꺼짐 방지
  js/main.js            시작
  assets/               이미지 시트에서 잘라 낸 리소스 (아래 표)
  manifest.webmanifest, sw.js, icon-*.png   홈 화면 설치·오프라인
  tests/                단위 테스트, 밸런스 시뮬레이션, 브라우저 점검
  tools/                시트 자르기, 서비스 워커 캐시 목록 생성
```

| 폴더 | 내용 | 원본 시트 |
| --- | --- | --- |
| `assets/bg` | 메인 메뉴, 숲·도시·설산·동굴·지옥 지역, 전투, 상점, 이벤트 배경 | 배경·UI 시트 |
| `assets/nodes` | 일반 전투, 정예, 상점, 보물, 휴식, 이벤트, 보스, 미지의 노드 | UI·아이콘 시트, 배경·UI 시트 |
| `assets/chars` | 플레이어(여행자)와 NPC 8명 (얼굴·어깨 위주로 자름) | 캐릭터 시트 |
| `assets/monsters`, `assets/bosses` | 일반·정예 몬스터 5종, 보스 4종 | 캐릭터 시트 |
| `assets/dice` | 주사위 1~6 | UI·아이콘 시트 |
| `assets/icons` | 출혈·빙결·방어·화상·회복 상태 아이콘, 픽셀 아이템 | UI·아이콘 시트 |
| `assets/relics`, `assets/potions` | 유물 23종, 소모품 8종 아이콘 | 배경·UI 시트 |
| `assets/fx` | 공격·회복·방어 이펙트 (검은 바탕, `mix-blend-mode: screen`) | 배경·UI 시트 |
| `assets/ui` | 로고, 프레임, 버튼, 둥근 버튼, 보물 상자 연출 | 두 시트 |
| `assets/bossicons`, `assets/emblems` | 보스 마커, 업적 문장 | 배경·UI 시트 |

시트에 들어 있던 글자(이름표, 설명, 제목)는 잘라 낼 때 모두 제외했습니다. 리소스를 다시 만들려면 원본 시트 세 장을 준비해서 다음을 실행합니다.

```bash
pip install pillow numpy
python3 dicebound/tools/cut_sheets.py <UI·아이콘 시트(마젠타 배경)> <캐릭터 시트> <배경·UI 시트> dicebound/assets
```

고해상도 원본이 생기면 `assets/` 안의 같은 파일 이름으로 바꿔 넣기만 하면 됩니다(배경·초상은 `jpg`, 투명 이미지는 `webp`).

## 저장

- 진행 중인 여정, 도감·업적·통계, 설정을 기기의 `localStorage`에 저장합니다(`dicebound.run.v1`, `dicebound.meta.v1`, `dicebound.settings.v1`).
- 모든 행동이 끝날 때마다 저장하므로, 창을 닫았다가 다시 열면 메인 메뉴의 `이어하기`로 같은 상태에서 계속할 수 있습니다.

## 점검

```bash
node dicebound/tests/rules.test.js          # 족보·공격 계산·맵 생성 단위 테스트
node dicebound/tests/sim.js 800             # 봇으로 800번 끝까지 진행 (규칙 위반·진행 막힘 검사, 승률)
python3 -m http.server 8765 &               # 저장소 루트에서
NODE_PATH=$(npm root -g) node dicebound/tests/e2e.js e2e-out 3   # 화면 크기별 캡처 + 버튼 클릭으로 여정 완주
```

## 아직 구현하지 않은 것

- 사운드와 배경 음악은 없습니다.
- 캐릭터 시트의 작은 픽셀 스프라이트(걷기·전투 동작), "몬스터 전투 맵 연출 예시", 배경 소품, 우편·공유 버튼은 사용하지 않았습니다. 전투 연출은 초상 흔들림과 이펙트 이미지로 표현합니다.
- 플레이어 캐릭터는 여행자 한 명뿐이고, 캐릭터 선택은 없습니다.
- 이미지 시트가 1536×1024 크기여서 잘라 낸 배경과 초상은 해상도가 낮습니다. 화면에서는 흐림과 어두운 그라데이션으로 보완했습니다.
- 밸런스는 단순한 봇(승률 약 57%) 기준으로만 맞췄고, 사람이 직접 플레이한 테스트는 하지 않았습니다.
- 여정은 1막(10층 + 보스)뿐이며, 난이도 선택은 없습니다.
