# DICEBOUND — 운명의 주사위

브라우저에서 실행하는 싱글 플레이 주사위 로그라이크 프로토타입입니다.

## 실행 방법
1. `index.html`, `style.css`, `game.js`를 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 엽니다. 별도 설치나 빌드 과정은 없습니다.
3. 로컬 서버를 사용하고 싶다면 프로젝트 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.

## 현재 포함된 기능
- 5개 주사위, 최대 3회 굴림, 잠금/재굴림
- 포커식 족보 판정과 공격 피해
- 일반/정예/보스 전투
- 특수 주사위와 유물
- 분기형 노드 선택, 보물, 상점, 휴식, 이벤트
- 보상, 체력, 골드, 승리/패배와 새 게임

## 프로토타입 한계
- 저장 기능은 아직 없습니다.
- 일부 밸런스와 효과는 플레이 테스트용 초깃값입니다.
- 전투 로그와 족보 피해 공식은 이후 테스트와 함께 다듬어야 합니다.
- 화면은 외부 폰트가 연결될 경우 Google Fonts를 사용합니다. 연결이 없어도 기본 폰트로 표시됩니다.
